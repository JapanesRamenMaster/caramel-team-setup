# /lms — 카라멜 LMS/SMS/MMS 발송

## 채널 차이

| 채널 | 한글 글자수 | 제목 | 이미지 | 용도 |
|------|------|------|--------|------|
| SMS  | ~45자 (90바이트) | X | X | 인증번호, 짧은 알림 |
| LMS  | ~1000자 (2000바이트) | O | X | 안내·마케팅 (대부분의 경우) |
| MMS  | ~1000자 + 이미지 1장 | O | O (jpg, ≤300KB, ≤1500x1440) | 시각자료 포함 안내 |

자동 채널 선택:
- 본문 ≤ 90바이트(한글=2, ASCII=1, 줄바꿈=1) → **SMS** 가능
- 본문이 그보다 길거나 제목이 있으면 → **LMS** 디폴트
- 이미지 첨부 → **MMS**

사용자가 채널을 명시 안 하면 LMS로 가정 (가장 자주 쓰는 채널).

## 발신번호 화이트리스트
caramel-sales-admin SmsSender에 등록된 번호만 사용 가능. 이외는 게이트웨이가 reject.

| 번호 | 주인 | 비고 |
|------|------|------|
| `15445932` | 사무실 1544-5932 | **디폴트 — 당번은 이것만 쓴다** |

개인 번호도 일부 등록돼 있으나 발신 주체가 회사가 아니게 되므로 당번 업무에서는 쓰지 않는다.
현재 등록 목록은 caramel-sales-admin > SmsSender에서 확인.

## 무료수신거부 문구 (자동 추가)

본문 끝에 자동으로 다음을 붙임:
```

[무료수신거부] 0808701439
```
- 본문에 이미 `[무료수신거부]`가 들어있으면 중복 추가 안 함
- 빼고 싶으면 `--no-suffix` 옵션
- 광고성/정보성 무관 디폴트 ON (사용자 운영 정책)

## 워크플로우

### 1. 정보 수집
사용자에게 누락된 항목만 묻는다 — 한 번에 모아서 묻지 말고 자연스럽게.

필수: 받는번호(또는 CSV), 본문
선택: 채널 (디폴트 LMS), 제목 (LMS/MMS), 발신번호 (디폴트 사무실), 예약시각

### 2. 미리보기 (반드시 출력)
```
[발송 미리보기]
채널: LMS
발신: 1522-8574 (사무실)
받는 번호: N명 (개인화 여부)
제목: <subject>
본문 (X바이트):
---
<content>  ← 무료수신거부 문구 포함된 최종본
---
messageGroup: claude_<timestamp>
```

개인화 발송이면 첫 1~2명 치환 결과를 같이 보여주기.

### 3. Confirm (안전장치)
- **받는 사람이 실행자 본인 번호뿐**(테스트 발송): 그냥 보낸다
- **그 외 (고객이 1명이라도 포함)**: 반드시 명시적 yes 받기
  > 이대로 N명에게 발송할까? (yes/no)

  사용자가 "네/응/yes/ㅇ/ok/발송해줘" 같은 명확한 긍정 안 하면 발송 금지.
- **100명 이상 대량**: 비용 환기 + 한 번 더 확인
  > 비용 발생 (~N건). 진행할까?

### 4. 발송

**단일 본문 (모두 같은 내용):**
```bash
~/.claude/skills/lms/lms-send.js \
  --to <CSV번호> \
  --channel LMS \
  --subject <제목> \
  --content <본문>
```
- caramel-api 백엔드가 30명씩 청크해서 처리 (한 번 호출 OK)

**개인화 (사람마다 다른 변수):**
CSV 파일 형식: `phone,var1,var2,...` (한 줄에 한 명)
```
01012345678,홍길동,8/24,5000원
01098765432,김철수,9/15,3000원
```

```bash
~/.claude/skills/lms/lms-send.js \
  --csv-file recipients.csv \
  --channel LMS \
  --subject "$1님 안내" \
  --content "안녕하세요 $1님, $2 일정에 $3 쿠폰을 드립니다."
```
- 우리 wrapper가 30명씩 동시 발송 (Promise.allSettled), 청크 사이 0.5초 sleep
- 진행률 실시간 출력 (`진행: 30/250 (성공 30, 실패 0)`)
- 실패한 번호는 마지막에 따로 리포트
- `--concurrency N`으로 동시 발송 수 조절 (기본 30)

CSV 텍스트를 직접 전달하려면 `--csv "01012345678,홍길동,8/24"` (개행 포함 가능)

### 5. 결과 보고
- 단일: `OK (N명)`
- 개인화: `완료: 총 N, 성공 X, 실패 Y` + 실패 목록
- 실패: HTTP 코드 + 에러 본문 그대로 (가공하지 말 것 — 디버깅 정보 보존)

## 변수치환 ($1, $2)

- 본문/제목 둘 다 변수 사용 가능
- 두자리 변수($10, $11, ...)도 지원 (큰 숫자부터 치환)
- 변수 이스케이프 필요 시 다른 placeholder(`{1}`)로 임시 변환 후 치환 — 일반적으론 안 씀

CSV 첫 컬럼은 항상 전화번호. 변수는 두번째 컬럼부터(`$1`, `$2`, ...).

## 대량 발송 청크 정책

- caramel-api 백엔드: `chunk(dto.to, 30)` — 단일 본문이면 한 번 호출에 dto.to 전체 전달 OK
- 우리 wrapper (개인화): 30명씩 `Promise.allSettled` + 청크 사이 500ms sleep
- 100명 = 약 4초, 1000명 = 약 35초 예상 (네트워크/백엔드 응답에 따라 변동)

## 주의

### 발송 비용
LMS 발송은 비용 발생. 대량 발송 (>100명) 전엔 한 번 더 확인.

### messageGroup
어드민에선 "실험 identifier"라 부르는 추적용 식별자. 우리는 자동으로 `claude_<unixtime>` 사용 — 사용자가 의미 있는 이름 주면 그걸로 (`claude_resurrection_test_0505` 같은). 같은 캠페인 결과 분석할 때 쓰임.

### 자격증명
- 위치: `~/.config/caramel/admin.env` (chmod 600)
- 계정: 어드민 공용 계정 (팀 셋업 시 전달받음)
- ADMIN_TOOLS 권한 필요

## Dry run
실제 발송 없이 페이로드만 보고 싶으면:
```bash
~/.claude/skills/lms/lms-send.js --to ... --dry-run
~/.claude/skills/lms/lms-send.js --csv-file ... --content ... --dry-run  # 첫 3명 치환 미리보기
```
대량 발송 / 개인화 전엔 항상 dry-run으로 한 번 확인할 것.

## 실패 패턴 (피할 것)

- ❌ Confirm 없이 외부 번호로 발송
- ❌ 채널 임의 결정 (사용자가 "LMS"라 했는데 SMS로 보내기 등)
- ❌ 본문 임의 수정 (오타라도 사용자에게 확인 받기)
- ❌ 발신번호 화이트리스트 외 사용
- ❌ "보냈어"라고만 하고 발송 결과 (성공/실패) 안 보고
- ❌ 100명+ 대량 발송 전에 비용 환기 안 함
- ❌ 개인화 발송 시 변수 치환 결과 미리보기 안 보여줌
