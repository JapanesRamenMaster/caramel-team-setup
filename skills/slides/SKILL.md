# /slides — 슬라이드 자동화

템플릿 PPTX의 슬라이드를 **복제**하고 **텍스트만 교체**하여 PPTX를 생성한다.
디자인을 코드로 새로 그리지 않는다. 템플릿의 도형, 배경, 서식을 그대로 보존한다.

---

## 절대 규칙 (위반 금지)

### 디자인
1. **텍스트만 교체**: 템플릿 슬라이드를 복제한 뒤 shape의 텍스트만 바꾼다. 서식(폰트, 크기, 색상, 정렬)은 원본 그대로 보존
2. **스타일 임의 지정 금지**: 머릿글, 제목, 본문 등의 폰트/크기/색상을 절대 코드에서 새로 지정하지 않는다
3. **콘텐츠 텍스트 최소 24pt**: 빔 프로젝션을 가정. 페이지 제목/카드 제목/본문/소제목 모두 24pt 이상. 예외는 메타 정보(좌상단 슬라이드 제목, 우상단 페이지 넘버, 데이터소스, 저작권)뿐 — 시각적 위계를 위해 작게 둔다
4. **placeholder 이미지 삭제**: 이미지를 교체할 때 기존 placeholder 이미지를 반드시 삭제한 후 삽입
5. **키컬러**: #FE5B1B (Primary/Orange-55). 강조가 필요한 곳에만 사용
6. **색상 토큰만 사용**: #FE5B1B, #2F3238, #5B5F66, #797E85, #A6ABB3, #EBEDF0, #FFFFFF, #F5F7FA 외 임의 색상 금지

### 구조
7. **슬라이드 제목 + 페이지 넘버링**: 표지와 인사 슬라이드를 제외한 모든 슬라이드에 반드시 포함. 절대 누락 금지
8. **첫 장 = 표지(slide[0])**, **마지막 장 = 인사(slide[19])**: 항상. 인사 슬라이드의 기본 텍스트는 "감사합니다"
9. **페이지 제목**: 쉽게 읽히는 한 문장 또는 핵심 단어. 장황하게 쓰지 않는다

### 워크플로우
10. **계획 먼저, 확인 후 제작**: 내용을 받으면 페이지별 초안(레이아웃 + 제목 + 내용)을 먼저 보여주고, 확인받은 뒤 PPTX 생성
11. **가정 금지**: 모르면 물어본다. 레이아웃 선택, 내용 배치에서 넘겨짚지 않는다

## 디자인 시스템

> **원칙: 콘텐츠 텍스트 최소 24pt**
> 빔 프로젝션을 가정. 콘텐츠 토큰(Title/Header/Body/Subtitle)은 모두 24pt 이상.
> 예외는 메타 토큰(좌상단 슬라이드 제목, 우상단 페이지 넘버, 데이터소스, 저작권) — 시각적 위계 유지를 위해 의도적으로 작게.

### 텍스트 스타일 (목표 사양)

#### 콘텐츠 토큰 — 모두 24pt 이상
| 토큰 | 크기 | 굵기 | 색상 | 용도 |
|------|------|------|------|------|
| Title | 40pt | Bold | 상황별 | 표지 제목, 비교 수치 |
| Header1 | 36pt | Bold | #2F3238 | 인덱스 번호/제목, 수치 기본 |
| Header2 | 28pt | Bold | #2F3238 | 페이지 제목 |
| Header3 | 24pt | Bold | #2F3238 | 카드 제목, 지표 이름 |
| Subtitle | 24pt | Regular | #FFFFFF | 표지 소제목 |
| Body | 24pt | Regular | #2F3238 | 설명 텍스트, 인용문, 보조 설명 (Body1/Body2 통합) |

#### 메타 토큰 — 24pt 룰 예외 (의도된 작음)
| 토큰 | 크기 | 굵기 | 색상 | 용도 |
|------|------|------|------|------|
| Meta | 12pt | Regular | #797E85 | 좌상단 슬라이드 제목, 우상단 페이지 넘버, 데이터소스 |
| Caption | 10pt | Regular | #A6ABB3 | 저작권 |

**특수 패턴:**
- 번호 라벨 (01, 02, 03): Bold + #FE5B1B
- 하이라이트 텍스트: Bold + #FE5B1B
- 비강조 카드 텍스트: #6D727A
- 인사말: 36pt Bold #FFFFFF (다크 배경)

> ⚠️ **현재 템플릿 동기화 상태**: `템플릿.pptx`는 v3.0 사양(Header2=23pt, Body1=14pt 등)으로 만들어져 있어 실제 렌더 시 24pt 룰을 충족하지 않는다. **위 사양을 충족하려면 템플릿을 v3.1 기준으로 재작업해야 한다.** 재작업 전까지는 PPTX 생성 후 사용자에게 "현재 템플릿은 v3.0 기준 — 24pt 룰 미적용"을 명시할 것.

## 세부 규칙

### 페이지 제목
- **제목만 읽어도 PPT 전체 흐름이 이해되게** 작성
- 쉽게 읽히는 한 문장 또는 핵심 단어. 장황 금지
- 좋은 예: "이동 부담이 크게 줄어듭니다", "이렇게 달라집니다", "본인 구역을 확인하세요"
- 나쁜 예: "구역 재배정 주요 변경 사항 안내", "배정 결과 확인 방법에 대한 설명"

### 레이아웃 선택

#### 의도 기반 선택 (최우선)

레이아웃은 "데이터가 뭔지"가 아니라 **"이걸로 뭘 전달하려는지"**로 고른다.

| 전달 의도 | 레이아웃 | src_slide |
|---|---|---|
| 숫자를 크게 보여주고 싶다 | 핵심지표 기본 | 5 |
| 숫자 + 맥락 설명이 필요하다 | 핵심지표 강조 | 6 |
| 원인/이유/항목을 나열하고 싶다 | 병렬 3단 | 10 |
| 2가지를 나란히 소개하고 싶다 | 병렬 2단 | 11 |
| A vs B를 대비시키고 싶다 | 비교 2단 | 8 |
| A vs B vs C를 대비시키고 싶다 | 비교 3단 | 9 |
| 한 문장으로 주목시키고 싶다 | 인덱스 변형 (번호 제거) | 3 |
| 시간순 흐름을 보여주고 싶다 | 타임라인 | 16/17 |
| 고객 목소리를 인용하고 싶다 | 인용 | 14/15 |
| 이미지가 핵심이다 | 이미지 강조 | 12 |
| 이미지 + 설명이 필요하다 | 이미지+텍스트 | 13 |

**판단 순서**: ① 이 슬라이드로 뭘 전달하려는지 → ② 위 표에서 의도 매칭 → ③ 레이아웃 매핑 테이블에서 text_map 확인

#### 매핑이 애매할 때

레이아웃 선택이 확실하지 않으면 **사용자에게 질문**한다. 임의로 고르지 말 것.

#### 사전 확인 필수

PPTX 생성 전에 **"내용 → 레이아웃" 매핑 초안**을 먼저 보여주고 사용자 확인을 받는다. 확인 없이 바로 생성하지 않는다.

```
예시:
| 슬라이드 | 내용 | 레이아웃 | 이유 |
|---|---|---|---|
| 3 | 4월 목표 미달 원인 | 병렬 3단 (slide[10]) | 원인 3가지 나열 |
| 4 | 세차 완료 + 매출 | 핵심지표 기본 (slide[5]) | 숫자 강조 |
```

#### 기존 규칙
- **수치 1개 강조** → 핵심 지표_수치 강조(slide[6]), 좌/우 컬럼 hide하고 가운데만
- **이미지 없으면 이미지 레이아웃 쓰지 말 것** → 다른 레이아웃 선택
- **TBD/미확정 내용** → 알려진 항목 목록이라도 넣을 것. 빈 슬라이드 금지
- **인덱스** → 목차가 아님. 각 섹션 시작 지점에 배치. 하위 페이지 3장 이하면 생략

### 유동적 변형 (허용)
- 컬럼 수 변경 (2→3→4): 총 너비 내에서 균등 분배
- 행 수 변경: 콘텐츠에 맞게
- 타임라인 구간 수 변경
- 막대 차트 bar 수 변경
- 사용하지 않는 컬럼/요소는 hide_shapes로 화면 밖 이동

### 표(Table) 스타일
- 헤더 행: #2F3238 배경 + #FFFFFF 텍스트 + 볼드
- 교대 행: #FFFFFF / #EBEDF0
- 합계 행: 배경색 없이(교대 규칙 따름) 텍스트만 볼드
- 세로선 없음 (컨설팅 스타일)
- 첫 열(항목명): 좌측 정렬, 나머지: 중앙 정렬
- 강조 수치: #FE5B1B + 볼드
- 폰트: Pretendard

### 차트 스타일
- matplotlib로 이미지 생성 → **PNG 투명 배경** → 슬라이드에 삽입
- 차트 막대/기본색: #EBEDF0
- 강조 막대/값: #FE5B1B
- 축 라벨: #797E85
- 값 라벨: #2F3238 (강조 시 #FE5B1B)
- 테두리: #EBEDF0, 상단/우측 테두리 없음
- Y축 숨김, 값은 막대 위에 직접 표기

### 링크
- URL은 반드시 **하이퍼링크**로 삽입. 텍스트로만 적지 말 것

### 이미지
- 삽입 시 기존 placeholder 이미지 **반드시 삭제** 후 삽입

## 실행 방법

### 스크립트
```bash
python3 ~/caramel-claude/slides/pptx_create.py \
  --template ~/caramel-claude/slides/템플릿.pptx \
  --spec spec.json \
  --output output.pptx
```

### 스펙 JSON 형식
```json
{
  "slides": [
    {
      "label": "설명",
      "src_slide": 0,
      "text_map": { "Text 1": "새 텍스트" },
      "hyperlinks": { "Text 4": "https://example.com" },
      "hide_shapes": ["Shape 0", "Shape 1"]
    }
  ]
}
```

- `src_slide`: 복제할 템플릿 슬라이드 인덱스
- `text_map`: {shape name: 새 텍스트} — 서식 보존
- `hyperlinks`: {shape name: URL} — 해당 shape에 하이퍼링크 추가
- `hide_shapes`: 숨길 shape name 목록 (화면 밖 이동)
