# /slides 사용 가이드

Claude Code에서 `/slides`를 입력하면 슬라이드를 자동으로 만들어줍니다.

---

## 처음 설정 (1회만)

Claude Code에서 이렇게 말하세요:

```
슬라이드 환경 세팅해줘
```

자동으로 필요한 패키지를 설치해줍니다.

---

## 빠른 시작

Claude Code에서 이렇게 말하면 됩니다:

```
슬라이드 만들어줘. 내용은:

제목: 4월 운영 리포트
- NPS 74점 달성 (전월 대비 +2)
- 세차 완료 4,500건
- 신규 구독 320건
- 다음 달 목표: 5,000건 돌파
```

Claude가 **먼저 초안**(어떤 레이아웃을 쓸지, 각 페이지 제목과 내용)을 보여줍니다. 확인하면 PPTX를 생성합니다.

---

## 할 수 있는 것

### 1. 내용 → 슬라이드 생성
텍스트를 주면 적절한 레이아웃을 선택해서 PPTX를 만듭니다.

```
이 내용으로 발표 자료 만들어줘:
[내용 붙여넣기]
```

### 2. 데이터 → 차트/표 슬라이드
CSV 파일이나 데이터를 주면 차트 또는 표로 만듭니다.

```
이 데이터로 차트 슬라이드 만들어줘
[CSV 첨부 또는 데이터 붙여넣기]
```

### 3. 기존 PPTX 수정
```
Downloads/발표자료.pptx에서 3번 슬라이드 제목을 "4월 성과"로 바꿔줘
```

---

## 사용 가능한 레이아웃

| 이름 | 용도 | 예시 |
|------|------|------|
| **표지** | 발표 시작 | "3월 정책 변경 안내" |
| **문장 강조** | 핵심 메시지 1문장 | "고객 만족도가 20% 올랐습니다" |
| **인덱스** | 섹션 시작 구분 | 큰 주제가 바뀔 때 |
| **핵심 지표** (3종) | 주요 수치 | "36% 감소", "3,500대+" |
| **비교** (2단/3단) | A vs B | 전분기 vs 이번 분기 |
| **병렬** (2단/3단) | 항목 나열 | 01 구독 확대, 02 품질 강화 |
| **이미지 강조** | 스크린샷/사진 | 제품 화면, 대시보드 캡처 |
| **이미지+텍스트** | 이미지 + 설명 | 스크린샷 + 기능 설명 |
| **표** | 데이터 테이블 | 월별 실적, 비교표 |
| **차트** | 막대/라인 차트 | 매출 추이, 지표 비교 |
| **인용** (1개/3개) | 고객 VOC | "카라멜 덕분에..." |
| **타임라인** (2종) | 일정/로드맵 | Q1~Q4 계획 |
| **자유 변형** | 기타 | 빈 슬라이드에 자유 배치 |
| **인사** | 마지막 장 | "감사합니다" |

## 디자인 시스템

모든 슬라이드는 카라멜 팀 디자인 시스템을 자동으로 따릅니다.

### 폰트
Pretendard 단일 서체. 용도별 크기/굵기가 정해져 있습니다.

| 용도 | 크기 | 굵기 | 예시 |
|------|------|------|------|
| 표지 제목 | 40pt | Bold | "3월 정책 변경 안내" |
| 인덱스/수치 | 30pt | Bold | "01", "99%" |
| 페이지 제목 | 23pt | Bold | "이동 부담이 크게 줄어듭니다" |
| 카드 제목 | 17pt | Bold | "팀 단위 편성" |
| 표지 소제목 | 16pt | Regular | "시행일 2026.3.9(월)" |
| 설명 텍스트 | 14pt | Regular | 본문 설명 |
| 보조 설명 | 12pt | Regular | 세그먼트 부연 설명 |
| 슬라이드 제목/넘버 | 9pt | Regular | 좌상단/우상단 |

### 색상

| 색상 | HEX | 용도 |
|------|-----|------|
| 오렌지 (키컬러) | `#FE5B1B` | 강조, 번호, 하이라이트 |
| 다크 | `#2F3238` | 본문 텍스트, 헤더 배경 |
| 회색 | `#797E85` | 슬라이드 제목, 보조 정보 |
| 연회색 | `#EBEDF0` | 카드 배경, 표 교대행 |
| 흰색 | `#FFFFFF` | 배경, 다크 위 텍스트 |

### 표 스타일
- 헤더: 다크 배경 + 흰색 텍스트
- 교대 행: 흰색 / 연회색
- 세로선 없음 (컨설팅 스타일)
- 합계행: 볼드만 (배경색 동일)

### 차트 스타일
- 기본 막대: 연회색 (`#EBEDF0`)
- 강조 막대: 오렌지 (`#FE5B1B`)
- 투명 배경 PNG로 생성

## 팁

- **내용만 주면 됩니다** — 레이아웃은 Claude가 선택. "비교 레이아웃으로 해줘"처럼 지정도 가능
- **초안에서 수정 가능** — "3장은 표로 바꿔줘", "인덱스 빼줘" 등 자유롭게
- **제목이 중요** — 제목만 읽어도 PPT 전체 흐름이 이해되게 작성됩니다
- **링크는 자동 하이퍼링크** — URL이 포함되면 클릭 가능한 하이퍼링크로 삽입
- **PPTX는 Downloads 폴더에 저장됩니다**
- **생성 후 파워포인트에서 추가 편집 가능** — 텍스트 수정, 이미지 교체 등
