# 표현 단위 패턴

표기 — **[관찰]** 은 LLM 출력에서 반복 관찰된 것, **[규범]** 은 국립국어원 규범으로 확인되는 것.

목록 뼈대는 stop-slop-ko에서 이어받았다. 각 절의 면제·예외와 우리 규칙과의 접점(고객 카피의 과장 형용사, 지표 주어, `질문 : 답` 헤더, 슬랙 청유형)은 우리 표면에서 붙였다.

## 단정 회피 어미 [관찰]

주장을 흐리는 어미. 불확실성이 실제로 있으면 무엇이 불확실한지 쓰고, 없으면 직접 말한다.

| 쓴 것 | 고칠 것 |
|---|---|
| `~라고 할 수 있습니다` | `~입니다` |
| `~것으로 볼 수 있습니다` | `~입니다` / `~으로 보입니다` |
| `~라고 생각됩니다` | `~라고 생각합니다` |
| `~인 것 같습니다` (판단에) | `~입니다` |
| `~한 경향이 있습니다` | 수치나 사례로 |
| `~할 수 있을 것입니다` | `~합니다` |
| `~일 수도 있습니다` (근거 없이) | 삭제하거나 근거를 붙인다 |
| `~하는 방향으로 검토해볼 수 있을 것 같습니다` | `~를 검토하겠습니다` |

**우리 규칙과 겹치는 지점.** 모르는 것은 `확인 필요`라고 쓴다. 어미로 흐리는 것과 모른다고 쓰는 것은 다르다.

## 공허한 강조어 [관찰]

정보 없이 중요해 보이게 만드는 장식. 뒤에 오는 내용이 스스로 중요하면 강조어가 필요 없다.

`중요한 것은`, `핵심은`, `주목할 점은`, `무엇보다도`, `결국에는`, `사실은`, `실제로는`, `본질적으로`, `근본적으로`, `궁극적으로`, `분명한 것은`, `한 가지 확실한 것은`

## 공허한 수식어 [관찰]

`다양한`, `여러`, `각종`, `효율적인`, `체계적인`, `전반적인`, `포괄적인`, `심층적인`, `혁신적인`, `전략적인`, `유의미한`, `적절한`, `필요한`, `지속 가능한`

원문에 그 내용이 있으면 나열하고, 없으면 구절째 지운다. `다양한 요인` → 요인이 원문에 있으면 나열, 없으면 삭제. 요인을 지어내지 않는다.

## 과장 형용사 [관찰]

| 쓴 것 | 고칠 것 |
|---|---|
| 놀라운 / 경이로운 | 무엇이 왜 놀라운지 수치로 |
| 강력한 / 막강한 | 무엇이 어떻게 강한지 |
| 압도적인 | 비교 대상과 차이 |
| 혁신적인 / 획기적인 | 이전과 무엇이 다른지 |
| 완벽한 / 최고의 | 거의 항상 과장이니 삭제 |
| 엄청난 / 어마어마한 | 규모를 숫자로 |
| 대폭 / 크게 | 몇 퍼센트인지 |

고객 카피에서도 면제되지 않는다. 컨시어지 톤은 정중함이지 과장이 아니다.

## 접속부사 남발 [관찰]

같은 접속부사가 단락마다 나오면 AI 티다. 단락당 1개 이하. 지워서 논리가 끊기는지 보고, 대부분 안 끊긴다.

| 인과 | 첨가 | 전환·요약 |
|---|---|---|
| 따라서 / 그러므로 | 또한 / 게다가 | **이를 통해** (최빈) |
| 그래서 | 더불어 / 아울러 | 이러한 맥락에서 |
| 결과적으로 / 그 결과 | 나아가 | 이와 같이 / 이처럼 |
| 이로 인해 / 이에 따라 | 뿐만 아니라 | 궁극적으로 / 결국 / 한편 |

## 서론 선언 [관찰]

`이 글에서는 ~를 다루겠습니다`, `오늘은 ~에 대해 이야기해보겠습니다`, `먼저 ~를 살펴보겠습니다`, `본 문서는 ~를 목적으로 합니다`, `~에 대한 이해를 돕기 위해`

**`살펴보다` 계열** — 문단을 넘길 때 붙이는 메타 서술. 거의 항상 삭제한다. `살펴보도록 하겠습니다`, `알아보겠습니다`, `짚어보고자 합니다`, `하나씩 살펴보면`, `자세히 들여다보면`, `이제 ~를 볼 차례입니다`

**예외 — 유일한 주제 문장.** 그 선언이 주제를 알리는 유일한 문장이면 지우지 말고 주장으로 다시 쓴다. `이 글에서는 온보딩 개선을 다루겠습니다` → `온보딩 절차를 손봐야 한다`.

## 공허한 결론 [관찰]

`이처럼 ~는 중요합니다`, `앞으로도 지속적인 관심이 필요합니다`, `함께 ~해야 할 것입니다`, `앞으로의 행보가 기대됩니다`, `한번 생각해보시기 바랍니다`, `도움이 되었으면 합니다`

마지막 문단은 실제 내용으로 끝낸다.

## AI 클리셰 [관찰]

| 의의 포장 | 변화 과장 | 시대 서사 |
|---|---|---|
| ~라는 점에서 의의가 있다 | 새로운 패러다임 | ~의 시대가 도래했다 |
| 시사하는 바가 크다 | 게임 체인저 | 급변하는 환경에서 |
| 중요한 시사점을 제공한다 | 새로운 지평을 열다 | 그 어느 때보다 중요해지고 있다 |
| 의미 있는 결과로 평가된다 | 패러다임의 전환 | 빠르게 변화하는 시장에서 |
| ~에 주목할 필요가 있다 | 전환점을 맞이하다 | 4차 산업혁명 시대를 맞아 |
| 귀추가 주목된다 | 판도를 바꾸다 | 바야흐로 ~ 시대다 |

`의의`, `시사점`, `패러다임`, `주목`이 나오면 멈추고 묻는다. 이 단어 대신 실제 내용을 쓸 수 있나.

## 막연한 권위 호소 [관찰]

| 쓴 것 | 문제 |
|---|---|
| `전문가들은 ~라고 말한다` | 어떤 전문가인가. 못 대면 직접 떠안는다 |
| `한 연구에 따르면` | 어느 연구인가. 출처를 달거나 삭제 |
| `많은 사람들이 ~라고 생각한다` | 근거 없는 다수결 |
| `일반적으로 ~로 여겨진다` | 수동태로 행위자를 숨긴다 |
| `~라는 것이 정설이다` | 정설이면 출처가 있다 |
| `업계에서는 ~라고 본다` | 업계는 말하지 않는다 |

## 사물 주어 [규범+관찰]

사람의 행동을 사물에 떠넘기는 것.

`데이터는 말해줍니다` → 분석한 사람이 결론을 낸다. `이 기술은 보여줍니다` → 누가 무엇을 했는지. `시장은 반응했습니다` → 구매자가 샀거나 안 샀다. `쿼리 결과는 시사합니다` → `쿼리해 보니 ~였다`.

**판정.** 주어가 무생물이고 동사가 판단·발화·반응·의도(말하다, 보여주다, 시사하다, 기대하다, 증명하다, 강조하다, 반응하다)면 걸린다. 서술·범위 동사(다루다, 포함하다, 구성되다)는 정상이다. `이 문서는 세 가지를 다룬다`는 격식 문어다.

**면제.** 지표를 주어로 쓰는 것은 걸린다. `전환율이 낮다`는 정상이지만 `전환율이 말해준다`는 걸린다.

## 과잉 경어 [관찰]

동사에 수동·가능·추정·격식을 겹쳐 쌓아 책임을 피하는 것.

`~하는 방향으로 검토해볼 수 있을 것 같습니다` → `~를 검토하겠습니다`. `~하시면 좋을 것 같습니다` → `~해주세요`.

**면제.** 고객 카피와 팀 부탁글의 정중한 어미는 유지한다. 겹침만 줄인다.

## 수사적 질문 [관찰]

바로 답하면서 던지는 질문. `왜 이것이 중요할까요?` → 이유부터 쓴다. `그렇다면 해결책은?` → 해결책을 쓴다.

**면제.** 슬랙 데이터공유형의 `질문 : 답` 헤더는 이 패턴이 아니다. 그것은 제목 형식이고 바로 답이 붙는다.

## 독자 참여 요청 [관찰]

`여러분은 어떻게 생각하시나요?`, `한번 생각해보시기 바랍니다`, `혹시 이런 경험 있으신가요?` → 삭제하고 요점으로.

**면제.** 슬랙 대화형의 청유형 마무리(`이렇게 가도 될까요?`)는 실제로 답을 요청하는 것이므로 정상이다. 답을 기대하지 않는 질문만 걸린다.

## 동어반복 부연 [관찰]

`즉`, `다시 말해`, `바꿔 말하면`으로 같은 말을 두 번 하는 것. `이는 곧 ~를 의미한다`(자명한 내용). 부연이 필요하다고 느끼면 원문이 불명확하다는 신호다. 처음부터 정확히 한 번 쓴다.

# 부록 — 규범 (slop과 별개)

slop을 다 잡은 뒤 정리 단계에서 적용한다.

**이중피동** [규범] — 피동 접사(`-이-/-히-/-리-/-기-`)와 `-어지다`를 겹치지 않는다.
보여지다 → 보이다, 되어지다 → 되다, 읽혀지다 → 읽히다, 여겨지다 → 여기다, 쓰여지다 → 쓰이다

**번역투** [규범]

| 쓴 것 | 고칠 것 |
|---|---|
| `~에 의해` | 능동문으로. `개발자에 의해 수정된` → `개발자가 수정한` |
| `~의` 연속 | 끊는다. `회사의 전략의 핵심의 문제` → `회사 전략의 핵심 문제` |
| `~하는 것이 중요하다` | `~해야 한다` |
| `~에 있어서` | `~에서` / `~에 관해` |
| `~를 통해` (수단) | `~해서` / `~로` |
| `~되고 있습니다` (상태) | `~중입니다` / `~합니다` |

한자어 순화(활용 → 사용, 구현 → 만든다)는 하지 않는다. 순화는 slop 신호가 아니고, 강제하면 레지스터가 납작해져 새 slop이 된다.
