## CS팀 추가 규칙

### 주요 업무
- 고객 예약/결제/환불 조회
- 고객 차량 정보 확인
- CS 통계 (환불율, 취소율 등)

### 자주 쓰는 조회 예시
- "010-1234-5678 고객 예약 내역 보여줘"
- "예약번호 12345 결제 상태 확인해줘"
- "홍길동 고객 차량 정보 알려줘"
- "이번 주 환불된 예약 목록"
- "오늘 취소된 예약 사유별로 정리해줘"

### 고객 응대 시 주의
- 고객 전화번호로 검색 시 `app_user.phone` 필드 사용
- 결과에 불필요한 개인정보 (주소 상세 등)는 빼고 보여줄 것
- 환불/취소 관련 조회 시 `payment.status`와 `reservation.status` 모두 확인
