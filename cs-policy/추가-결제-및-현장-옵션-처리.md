## 요약
세차 현장에서 추가 옵션이 발생하거나 현장 결제가 필요한 경우 처리 절차.

## 적용 조건
- 대상: 디테일러 전체
- 적용 상황: 현장에서 고객이 추가 옵션을 요청하거나 예약 외 추가 비용이 발생하는 경우

## 상세 내용

### 추가 옵션 요청 시
1. 고객에게 추가 옵션 비용과 소요 시간 안내
2. 고객 동의 후 디테일러 웹에서 추가 옵션 등록
3. 카드 결제 진행 (페이히어 단말기 사용)

### 추가 결제 수단
- **카드 결제**: 페이히어 단말기 사용 → 「페이히어 카드 단말기 사용 가이드」 참조
- **앱 결제**: 고객이 앱에서 직접 옵션 추가 후 결제 가능

### 현금 수수 금지
- 고객에게 현금을 받는 것은 금지. 반드시 카드(페이히어) 또는 앱 결제만 사용.

### 특수 오염으로 추가 비용 발생 시
- 예약 전 진단에서 발견하는 것이 원칙
- 발견 후 고객에게 고지하고 동의받아야 진행 가능
- 고지 없이 진행하고 사후 추가 청구 불가

### 다음 예약 빠듯할 때
추가 옵션 진행으로 다음 예약이 빠듯해질 경우:
- 옵션 진행 전 반드시 고객에게 시간 제약 안내
- 시간 내 완료 불가 시 다음 방문으로 나누어 진행 가능 여부 고객과 협의
