## 요약
1회성 세차 상품(외부만 / 외부+내부) 가격 문의 시 응대 기준. 가격은 차량 모델에 따라 상이하므로, 고객 차량 모델 확인 후 SSOT 차량별 티어 맵핑표에서 티어를 확인하고 이 문서의 가격표로 고객에게 직접 안내한다.

## 적용 조건
- 대상 고객: 전체
- 적용 상황: 1회성 세차 상품 가격을 문의하는 경우
- 적용 기간: 상시

## CS 처리 기준
- 고객 차량 모델 확인 → SSOT 차량별 티어 맵핑표에서 티어 확인 → 아래 가격표에서 해당 티어 가격 조회 → 고객에게 직접 안내 (앱 확인 안내 금지)

## 고객 안내 문구
안녕하세요, 고객님!
카라멜 고객서비스 팀입니다.

감사합니다.
> ⚠️ AI 안내 주의 — 아래 표는 내부 가격 조회용입니다. 티어(티어1~7, T1~T7) 명칭은 고객 응대 시 절대 노출하지 않습니다. 가격만 확인 후 "[차량 모델] 기준 OO원입니다" 형식으로 차량 모델과 금액만 안내하세요.
