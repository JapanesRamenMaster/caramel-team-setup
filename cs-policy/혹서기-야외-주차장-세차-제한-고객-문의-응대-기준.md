혹서기(2026-06-22~2026-09-06) 동안 야외 주차장 세차가 한시적으로 제한된다. 고객 문의 유형별 응대 기준을 안내한다.

## 적용 조건
- 대상 고객: 전체 (1회·구독 공통)
- 적용 기간: 2026-06-22(월) ~ 2026-09-06(토)
- 적용 상황: 야외 주차장 세차 제한 관련 고객 CS 문의

## 세차 가능·불가 기준
| 구분 | 가능 여부 |
| --- | --- |
| 지하주차장 | 가능 |
| 실내주차장 | 가능 |
| 개러지형 주차장 | 가능 (단, 세차 진행 전 모든 문 닫힘 확인 필요) |
| 야외 주차 (필로티, 개방형 지상 주차장 포함) | 불가 |

## CS 처리 기준
| 문의 유형 | 처리 |
| --- | --- |
| 여름철 야외 주차장 세차 제한 여부 확인 문의 | 제한 기간·불가 주차장 유형 안내. 지하·실내는 가능함 안내 |
| 야외 주차장인데 세차 가능 여부 문의 | 불가 안내 + 지하·실내 이동 가능 여부 확인 → 불가 시 전일 오후 8시 전 무상 취소 안내 (1회권: 환불 / 구독: 세차권 반환) |
| 필로티·개방형 주차장이 왜 불가냐 이의 | 햇빛·외기 직접 노출로 물·케미컬 증발 동일하게 발생함 안내. 앱 예약 시 사진으로 사전 안내된 내용임 고지 |
| 품질 미흡해도 괜찮으니 진행해달라는 요청 | 작업자 안전 + 자체 품질 기준 이유로 불가. 고객 동의 여부와 무관하게 원칙 유지 |
| 구독 이용 중인데 야외 주차장밖에 없음 | 예약 건별 전일 무상 취소 시 세차권 반환 안내. 또는 구독 일시정지·해지 안내 |
| 현장에서 실외 주차장 사유로 유료 취소 후 수수료 이의 제기 | 예약 전 별도 안내 화면에서 해당 항목 체크 동의 후 예약 진행 가능한 구조임을 안내 |
| 제한 기간 종료(9/7) 이후 야외 주차장 이용 가능 여부 문의 | 야외 주차장 세차 제한은 9/6(토)까지이며, 9/7(일)부터는 야외 주차장 포함 정상 이용 가능 안내 |

## 고객 안내 문구
[정책 확인 문의 시]
> 6/22(월)~9/6(토) 동안 야외 주차장(필로티·개방형 지상 포함)에서는 세차가 어렵습니다. 고온의 날씨에 물·케미컬이 빠르게 증발해 품질을 보장하기 어렵기 때문입니다.
[야외 주차장 세차 불가 안내 시]
> 고온의 날씨에는 물·케미컬이 빠르게 증발해 야외 주차장에서는 세차 품질을 보장하기 어렵습니다. 지하·실내주차장으로 차를 옮겨주시면 정상적으로 진행해 드릴 수 있습니다.
[품질 미흡해도 괜찮다고 진행해달라 하는 경우]
> 고온의 야외 환경에서는 작업자의 안전을 보장하기 어렵고, 저희 자체 품질 기준에 부합하는 결과물을 드리기도 어렵습니다. 
[구독 고객 이용 불가 시]
> 기간 동안 이용이 어려우신 경우, 예약 건별로 전날 저녁 8시 전에 무상 취소하시면 세차권이 반환됩니다. 
[현장에서 실외 주차장 사유로 유료 취소 후 수수료 이의 제기 시]
> 예약 진행 전 야외 주차장 세차 불가에 대한 별도 안내 화면이 표시되며, "현장 방문 후 야외 주차장으로 확인된 경우, 방문 비용 4만원을 제외하고 환불됩니다" 항목에 직접 체크 동의하셔야 예약을 진행하실 수 있는 구조입니다. 

## 예외 사항
- 개러지형 주차장은 세차 가능하나, 진행 전 모든 출입문이 닫혀 있는지 반드시 확인.
