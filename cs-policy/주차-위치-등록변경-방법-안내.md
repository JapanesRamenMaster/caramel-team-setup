## 요약
세차 당일 주차 위치를 디테일러에게 전달하는 방법을 문의하는 고객 안내 기준. 앱 등록, 전날 디테일러 연락, 직접 연락 세 가지 방법을 안내한다.

## 적용 조건
- 대상 고객: 전체
- 적용 상황: 세차 당일 주차 위치 전달 방법 문의 시, 또는 채널톡으로 주차 위치를 내론한 경우
- 적용 기간: 상시

## 고객 안내 문구
안녕하세요, 고객님!
주차 위치를 남겨주셨네요.
상세한 주차 위치 정보는 아래 세 가지 방법 중 편하신 방법으로 전달해 주시면 됩니다.
방법 1. 앱 내 직접 등록 (권장)
주차 완료 후 앱 내 좌측 하단 [내 차고] 탭 → [예정된 세차] 탭의 해당 예약건 하단의 [주차 위치 등록] 또는 [주차 위치 변경] 클릭
방법 2. 디테일러 방문 전날 연락 시 전달
세차 전날 디테일러가 먼저 연락을 드리고 있으니, 그때 말씨해 주셔도 됩니다.
방법 3. 디테일러에게 직접 연락
세차일 전일 오후 8시부터 앱 내 디테일러 연락처가 표시됩니다.
확인 방법: 카라멜 앱 → 좌측 하단 [내 차고] 탭 → 해당 예약 카드 최하단
번거로우시겠지만, 원활한 서비스 진행을 위해 부탁드립니다. 감사합니다!
