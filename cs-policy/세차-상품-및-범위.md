## 요약
카라멜 세차 상품 구성과 각 상품별 작업 범위 기준.

## 적용 조건
- 대상: 디테일러 전체, CS 응대 시 고객 안내용
- 적용 상황: 상품 설명 및 작업 범위 안내 시

## 상세 내용

### 상품 구성

| 구분 | 상품명 | 작업 범위 |
|---|---|---|
| 기본 | 기본 외부 | 외부 세차 전체 |
| 기본 | 기본 내외부 | 외부 세차 + 내부 청소 |
| 프리미엄 | 프리미엄 외부 | 기본 외부 + 휠 딥클리닝 + 왁스 코팅 |
| 프리미엄 | 프리미엄 내외부 | 프리미엄 외부 + 내부 청소 |

### 기본 외부 세차 작업 범위
- 차체 전체 세척 (거품 세차 + 헹굼 + 닦기)
- 유리 세척 (외부)
- 타이어·휠 기본 세척
- 도어 틈새 세척

### 기본 내부 청소 작업 범위 (내외부 상품에 포함)
- 실내 진공청소 (바닥 매트 포함)
- 대시보드 및 센터콘솔 닦기
- 시트 먼지 제거
- 유리 내부 닦기

### 프리미엄 추가 작업 (기본 대비 추가 사항)
- 휠 딥클리닝: 브레이크 더스트·오염 제거
- 왁스 코팅: 발수 효과 부여

### 유료 옵션 항목
- 엔진룸 세척
- 유리막 코팅
- 발수 코팅
- 반려동물 털 제거 (추가 공임)
- 석회물·시멘트물 제거 (폴리싱, 추가 공임)

옵션 상세 안내는 「유료 옵션 가이드」 참조.

### 작업 제외 항목 (기본 상품 기준)
- 엔진룸 내부 (옵션 별도)
- 트렁크 내부 청소 (짐이 있는 경우 — 고객 동의 없이 짐 이동 불가)
- 유리 외부 코팅 (발수 코팅은 옵션)
- 스크래치·덴트 등 도장 복원
