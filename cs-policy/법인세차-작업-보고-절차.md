## 요약
법인 계약 업체 세차 완료 후 작업 보고 방식 안내.
2026년 4월 2일부터 기존 카카오톡 문자 입력 방식에서 작업 보고 사이트 제출 방식으로 변경됩니다.

## 적용 조건
- 대상: 법인세차 업무 배정 디테일러
- 적용 업체: 한남 테슬라, 벤틀리, 마이바흐, 인천 테슬라, 헤이딜러
- 적용 기간: 2026.04.02부터 (카카오톡 사진 전송 병행 유지, 추후 간소화 예정)

## 상세 내용

### 1. 공통 보고 절차 (헤이딜러 제외)
적용 업체: 한남 테슬라, 벤틀리, 마이바흐, 인천 테슬라
변경 전: 각 업체 카카오톡방에 차량 정보 및 사진 직접 입력·전송
변경 후: 작업 보고 사이트 제출 + 각 업체 카카오톡방 사진 전송 병행
작업 보고 사이트 제출 방법:
1. https://jungsikson.github.io/-/ 접속
  - 반드시 주소를 복사하여 크롬에 붙여넣기. 북마크 저장 권장.
1. 기본 정보 입력: 날짜 선택, 본인 이름 입력, 업체 선택
1. 차량 등록: 차량번호 및 차종 입력
  - 여러 대 동시 등록 또는 한 대씩 등록 모두 가능
1. 각 업체 카카오톡방에 사진 전송
  - 사이트 제출 내역과 사진이 일치한다는 증빙 목적

### 2. 헤이딜러 보고 절차
변경 전: 이수민 팀장에게 카카오톡으로 차종·차번호·사진 전송
변경 후: 작업 보고 사이트 제출 + 이수민 팀장에게 사진만 카카오톡 전송
작업 보고 사이트 제출 방법:
1. https://jungsikson.github.io/-/ 접속
  - 반드시 주소를 복사하여 크롬에 붙여넣기. 북마크 저장 권장.
1. 기본 정보 입력: 날짜 선택, 본인 이름 입력, 업체 선택(헤이딜러)
1. 차량 등록: 차량번호 및 차종 입력
이수민 팀장 전달 방법:
- 사이트 제출 후 이수민 팀장에게 사진만 카카오톡으로 전송
- 차종·차번호 별도 텍스트 전송 불필요
  (이수민 팀장이 엑셀 시트에서 종합 확인 가능)
- 필요 시 사이트 내 제출 요약 또는 내역조회 화면을 캡처하여 전송 가능

### 3. 한남 테슬라 바디샵(와이엠서비스) 현장 작업 유의사항
- 1층 사무실에 먼저 방문하여 작업 시 주의사항을 안내받습니다.
- 차량 키는 우기정 부장님(010-4657-4540)이 보관 중이므로 필요 시 연락합니다.
- 카리프트를 이용하여 지하 2층으로 이동합니다.
  - 주의: 레이 차량 입차 시 안테나가 리프트 천장에 걸려 파손되지 않도록 각별히 주의합니다.
- 차량 내부에 비치된 작업지시서를 통해 수리가 완료된 부위를 확인합니다.
- 차량 내에 지시서가 없으면 즉시 1층 사무실에 문의하여 작업 범위를 확인받습니다.
- 수리·도장이 갓 끝난 부위는 미세한 마찰에도 민감합니다. 스크래치 발생 시 디테일러 과실로 처리되므로 평소보다 훨씬 조심스럽게 작업합니다.
- 트렁크 개폐 사고 방지: 트렁크를 끝까지 올릴 경우 상단 덕트 배관에 부딪혀 도장이 손상되는 사고가 이미 2건 발생했습니다. 전동 트렁크라도 반드시 손으로 직접 잡아 배관에 닿지 않도록 개방 각도를 조절합니다.
- 위 1항의 공통 보고 절차에 따라 사이트 제출 + 카카오톡방 사진 전송을 병행합니다.
- 사진 규정: 차량 번호를 명확히 식별할 수 있는 차량 전면 사진을 필수 전송합니다.
