## 요약
외부 세차 전 공정(STEP 1~5)과 특수 오염 선첫잡기, 겨울철 유의사항, 부위별 세부 가이드를 다룬다.

## 적용 조건
- 대상: 디테일러 전체
- 적용 상황: 외부 세차 진행 중 전 공정

## 상세 내용

### 외부 특수 오염 선첫잡기 (1차 이전)
외부 특수 오염은 1차 물 작업 이전에 먼저 조치한다. 이후 1~2차 물 작업으로 자연스럽게 마무리되도록 하기 위해서이다.
| 오염 종류 | 성분 분류 | 처리 방법 |
| --- | --- | --- |
| 도어캐치 손톱자국 | — | 올인원클리너로 불려놓고 닦기 |
| 앞범퍼 벌레 | 유기물 (단백질) | 1차 물 도포 시 더 많은 물로 충분히 불리기. 안 지워지면 손톱으로 밀어준 후 젬젬 여러 번 문지르기 (예외 없이 제거 가능) |
| 새똥 | 유기물 | 1차 물 고압으로 제거 시도 → 올인원클리너 |
| 석회물 | 무기물 (미네랄) | 고객 사전 안내 후 RV3000 → 필요 시 광택기 |
| 송진 | 유기물 (수지) | PB 또는 카빈레터클리너로 제거 |
| 타르 | 무기물 | RV3000, 물지염산, 약산성 세정제 |
유기물(기름·단백질) → 염기성 계면활성제(빨래세제류) / 무기물(돌·석회·미네랄·타르) → 산성 계면활성제(RV3000, 물지염산, 약산성)
---

### STEP 1. 외부 1차 — 물 도포
고압수로 큰 이물질을 흐려내리는 단계다. 스크래치 방지의 가장 중요한 조건은 수분의 유무이다. 아무리 깨끗한 타월, 깨끗한 도장이라도 수분 없이 마른 상태로 문지르면 반드시 스크래치가 생기므로, 물을 충분히 적신 후 닦는다.
부위별 살수 가이드
| 구역 | 살수 강도 | 이유 및 주의 |
| --- | --- | --- |
| 펜더·하부·뒤범퍼·하단부 | 집중 살수 | 오염 집중 구역. 염화칼슘·모래 다량 |
| 천장·보닛 | 흐를 정도 | 모래+먼지가 많지 않아 굴이 많이 듺 필요 없음 |
| 앞범퍼·번호판·앞유리·사이드미러 | 충분히 불림 | 벌레자국 등 불릴 시간 확보 |
| 사이드 스텝·문 손잡이 아랛부분 | 압력으로 제거 | 모래가 많은 곳 |
물이 빨리 마륲 때 대응
1. 충분히 많은 양의 물을 듚는다.
1. 그래도 말라붙는 경우: 반만 빰려 바로 닦아내기로 넘어간다.
1. 또는: 판(패널) 단위로 빰리고 → 닦고 → 다음 판 빰리고 → 닦는 방식으로 응용한다.
위치별 주의사항
- 옵 차량에 물이 튀지 않도록 최대한 조심
- 루프(지붕): 옆에서 빰리면 인근 차량에 튀므로, 앞뒤에서만 듹리기
- 문 틈새: 고압수를 직접 넣어 틈새 오염 및 염화칼슘 제거
- 앞·뒤 범퍼(포더 부분): 모래·낙엽 다량 부착 → 고압수로 충분히 제거
- BMW 그릴처럼 닦기 어려운 부분은 물로만 최대한 처리
물 사용량 기준
| 계절 | 타월 사용량 (차 1대) | 물 사용량 |
| --- | --- | --- |
| 봄·여름·가을 | 약 3장 | 적정량 |
| 겨울 (염화칼슘 시즌) | 7~10장 | 최대한 많이 |

### STEP 2. 외부 1차 — 닦아내기
큰 이물질을 도장면에서 ‘걸어내는’ 단계다. 기스(스크래치)가 발생할 가능성이 가장 높은 공정이므로, 힘주지 않고 가볍게 닦는다.
핵심 원칙
| 원칙 | 설명 |
| --- | --- |
| 목적 | 닦는 것이 아니라 ‘걸어내는’ 것. 힘을 최대한 빼고 가볍게 |
| 타월 사용 | 맙타월 최소 2장. 오염도·차 크기·물 양에 따라 추가 |
| 보닛 우선 | 오염도가 가장 낙을 빨리 마르는 부위 → 타월 상태가 가장 깨끗할 때 먼저 |
| 꽃 누르지 말 것 | 반드시 기스 발생. 한 번 닦은 곳 다시 닦지 않음 |
| 겹쳐서 닦기 | 10~20% 중첩(わ자 동선). 손가락이 닿은 부분을 손바닥으로 한 번 더 |
| 앉아서 닦기 | 눈으로 확인하지 않으면 반드시 누락 발생. 낙은 부위와 틈새 놓치지 않기 |
| 틈새 닦기 | 손가락이 안 들어가면 타월만 넣어서 닦기 |
| 허리 주의 | 손으로 짚고 세차하지 않으면 허리 부상. 올바른 자세 유지 |
맙타월 1 사용 순서 (1차 닦아내기)
| 타월 면 | 부위 | 세부 가이드 |
| --- | --- | --- |
| 0번 면 | 보닛 | 가볍게 닦기. 가장 깨끗한 면으로 시작 |
| 1번 면 | 운전석 앞 포더 | — |
| 2번 면 | 운전석 앞 유리 / 운전석 앞 천장 / 운전석 앞 창문 / 운전석 앞 문 | 유리: 도장면보다 기스 덜 나으므로 세 번 문질러 세정 가능. 와이퍼 들어서 안쪽까지 세정 (보닛에 닿지 않게 주의). 문: 손잡이 사이 손가락 넣어 꽈꽈히 세정. 하단까지 닦고 뒤집기 |
| 3번 면 | 운전석 뒤 천장 / 운전석 뒤 창문 / 운전석 뒤 문 | 문: 하단까지 닦고 뒤집기 |
| 4번 면 | 운전석 뒤 유리 / 트렁크 전체 / 운전석 뒤 포더 | 트렁크: 라이트 굴곡 틈새 공들여 세정 (안 하면 항상 잔사 남음). 번호판-트렁크 사이 빈 곳 신경쓰기. 후진 타월 교체 |
맙타월 2 사용 순서 (1차 닦아내기 계속)
| 타월 면 | 부위 | 세부 가이드 |
| --- | --- | --- |
| 1번 면 | 조수석 뒤 유리 / 트렁크 전체(한 번 더) / 조수석 뒤 포더 | — |
| 2번 면 | 조수석 뒤 천장 / 조수석 뒤 창문 / 조수석 뒤 문 | — |
| 3번 면 | 조수석 앞 천장 / 조수석 앞 창문 / 조수석 앞 문 | — |
| 4번 면 | 조수석 앞 유리 / 조수석 앞 포더 / 앞범퍼 전체 | 앞범퍼 가장 나중에 닦는 이유: 벌레자국 불리기 위해서. 쪩그려 앉아서 눈으로 확인하며 세정 필수. 벌레자국: 누르지 말고 젬젬 여러 번 문지르면 반드시 제거됨 |

### STEP 3. 휠 초벌
1차 닦기 후 사용한 타월로 분진 제거한다. 상식과 달리 휠은 세정제 없이도 잘 닦인다.
- 1차 사용 타월로 분진 제거
- 손가락이 안 들어가면 타월만 넣어서 세철 — 안 닦이는 경우 없음
- 닦은 부분과 안 닦은 부분을 구분하며 타월을 돌려 사용 (안 쓴 면 활용)
- 검지+엄지로 닦고, 볼트 부분은 손가락 넣어서 닦기
- 내가 보는 각도에서는 다 닦인 것처럼 보여도, 한 바퀴 돌면 안 닦인 곳 보임 → 클레임
- 1차 타월로 잘 안 지워지면 휠 세정제 사용 (1:10 희석)
폴리슈 휠, 아노다이징 휠에는 휠클리너 사용 금지. 마차휠은 닦아보고 안 되면 드레싱제로 코팅 처리.

### STEP 4. 외부 2차 — 케미컬 도포 + 닦아내기
광택·방오 효과 부여 및 마감 단계다.
케미컬(외부2차케미컬) 도포
외부2차케미컬을 도장면에 고르게 도포한다. 휠활력 증진으로 스크래치를 예방하고, 잔여 트래픽 필름을 제거하며, 광택·방수·방오 효과를 부여한다.
케미컬이 마르면 절대 안 된다. 말라붙으면 제거하는 데 순수한 물이 2~3배 필요하고 기스도 생긴다. 2차를 빨리 처리하려면 1차를 꽈꽈히 잘 진행해야 한다.
2차 닦아내기 원칙
- 1차를 잘 했다는 가정 하에 맙타월 1장으로 양쪽을 나누어 닦아냄
- 왕복 겹쳐닦기 — 손가락이 닿았던 부분을 손바닥으로 다시 겹쳐 닦는 개념
- 2차만 잘 해도 유리를 제외하고 별도 마감 없이 완성 수준이어야 함
- 많이 놓치는 곳: 타이어 뒤 포더, 보닛 삼각지, 유리창 삼각지, 휠하우스 도장 연장 부분
맙타월 3 사용 순서 (2차 닦아내기)
| 타월 면 | 부위 순서 |
| --- | --- |
| 1번 면 | 보닛 → 운전석 앞 포더 → 운전석 앞 유리 → 운전석 앞 천장 → 운전석 앞 창문 → 운전석 앞 문 |
| 2번 면 | 운전석 뒤 천장 → 운전석 뒤 창문 → 운전석 뒤 문 → 운전석 뒤 유리 → 트렁크 전체 → 운전석 뒤 포더 |
| 3번 면 | 조수석 뒤 유리 → 트렁크 전체(한 번 더) → 조수석 뒤 포더 → 조수석 뒤 천장 → 조수석 뒤 창문 → 조수석 뒤 문 |
| 4번 면 | 조수석 앞 천장 → 조수석 앞 창문 → 조수석 앞 문 → 조수석 앞 유리 → 조수석 앞 포더 → 앞범퍼 전체 |

### STEP 5. 외부 유리 마감
실내 진입 전 외부 유리·크롬 잔사를 완전히 제거한다. 반드시 내부 유리 닦기 전에 외부 유리를 먼저 마감한다. 내부 유리 작업 시 바깥에서 온 오염인지 안쪽 오염인지 구분이 안 되기 때문이다.
- 마른 극세사 타월로 잔사(물자국) 제거 — 별도 케미컬 불필요
- 타월에만 빰릴 것 (직분사 금지)
- 와이퍼 아래 및 숨겨진 부분도 마감
- 유리 외에도 크롬 부분(물자국 잘 보임) 이때 함께 마감
- 완스 눈르붙은 것·유막이 있으면 유리세정제 소량 사용 가능 — 타월에만 빰릴 것
유리 마감 순서
운전석 앞유리 → 사이드미러 → 운전석 창문 → 운전석 뒤 창문 → 뒤유리 → 조수석 뒤 창문 → 조수석 앞 창문 → 사이드미러 → 조수석 앞유리
유리별 잔사(물기) 제거 기준
| 유리 위치 | 제거 기준 | 비고 |
| --- | --- | --- |
| 앞 유리 (전면) | 100% 완전 제거 (와이퍼 하단 제외) | 와이퍼 작동 시 즉시 확인됨 |
| 운전석·조수석 창문 | 거의 100% 제거 | 창문 여닫을 때 확인됨 |
| 뒷좌석 창문 | 약 90% 수준 | 일반 고객 시야 기준 |
| 선루프 (있는 경우) | 닦기 권장 | 사다리 활용 |
---

### 겨울철 특별 유의사항
겨울철(염화칼슘 살포 시즌)은 외부 세차의 난이도가 가장 높다. 염화칼슘 성분이 남아있으면 검은 차를 깨끗이 닦아도 손으로 문지를 때 하얣게 된다. 제거 방법은 충분한 물량뿐이다.
| 구분 | 일반 시즌 (봄·여름·가을) | 겨울 시즌 |
| --- | --- | --- |
| 물량 | 적정량 | 최대한 많이 (흐러내리는 것 확인) |
| 타월 수 | 차 1대 약 3장 | 차 1대 7~10장 |
| 타월 교체 | 더러워지면 교체 | 조금 적었다 싶으면 즉시 교체 |
| 주요 오염 | 일반 먼지, 기름때 | 염화칼슘, 결빙 방지제 |
| 바닥 물 처리 | 자연 배수 | 물 고임 → 밀대로 제거 후 마무리 |
아파트 주차장: 물이 하수로 내려가지 않고 고임 → 작업 후 밀대로 처리. 문 틈새에 고인 물 → 동절기에는 얼 수 있으므로 특히 잡 빼줄 것.

| 엠블럼 / 로고 | 손가락으로 틈새 닦기 | 하이그로시 재질 스크래치 주의 | ★★ |
| 사이드 미러 | 위→아래, 겨쳐 닦기 | 물 고임 확인 | ★ |
