## 요약
현장 추가 결제 시 페이히어 단말기 사용 방법.

## 적용 조건
- 대상: 디테일러 전체
- 적용 상황: 현장에서 추가 옵션 결제 또는 현장 결제가 필요한 경우

## 상세 내용

### 기기 준비
- 단말기는 오퍼레이션 팀에서 배분하며, 업무 시작 전 배터리 충전 상태 확인
- 분실 또는 파손 즉시 오퍼레이션 매니저에게 보고

### 결제 방법
1. 페이히어 앱 또는 단말기 전원 켜기
2. 결제 금액 입력
3. 고객의 카드 또는 결제 수단으로 결제
4. 영수증 발급 (고객 요청 시) — 앱에서 문자 또는 카카오톡으로 발송 가능

### 결제 시 주의사항
- 현금 수취 금지 — 반드시 카드 또는 앱 결제만 허용
- 잘못된 금액 결제 시 즉시 취소 후 재결제 (오퍼레이션 매니저에게 보고)
- 결제 오류 발생 시 고객에게 앱 결제를 안내하고 오퍼레이션 매니저에게 보고

### 일일 마감
- 하루 업무 종료 후 단말기 충전 연결
- 당일 결제 내역 확인 후 이상 있으면 오퍼레이션 매니저에게 보고
