## 요약
구독 고객이 해지 또는 일시 정지를 요청하는 경우, 앱 내 직접 처리를 안내한다. CS 개입이 필요한 경우는 정지 기간 중 조기 재개 요청 시에만 해당한다.

## 적용 조건
- 대상 고객: 구독 고객 전체
- 적용 상황: 구독 해지 또는 일시 정지 문의 인입 시
- 적용 기간: 상시

## CS 처리 기준
해지 문의 접수 시 먼저 해지 사유가 **차량 변경**인지 확인한다. 차량 변경이 목적이라면 「구독 이용 중 차량 변경 문의 응대 기준」을 참조하여 안내한다.

차량 변경이 아닌 일반 해지/일시 정지 문의의 경우, 고객이 앱에서 직접 처리한다.

**앱 내 처리 경로:** 카라멜 앱 → 좌측 하단 \[내 차고\] 탭 → (차량이 여러 대인 경우) 상단에서 해당 차량 선택 → 우측 상단의 (구독상품명) 구독중> 버튼 선택 → \[구독 관리\] → \[해지\] 버튼

**해지 버튼 선택 후 두 가지 옵션:**

| 옵션 | 내용 |
|---|---|
| 구독 취소 | 구독 즉시 해지. 잔여 세차권은 \[세차권 다음에 사용하기\] 또는 \[세차권 환불 받기\] 중 선택 |
| 일시 정지 | 구독 결제를 일시적으로 중단. 정지 기간은 1개월 / 2개월 / 3개월 / 4개월 중 선택 |

## 세부 정책

**잔여 세차권**
- 구독을 통해 지급된 세차권은 별도 유효기간 없이 사용 가능
- 환불 선택 시: 해당 구독으로 취득한 전체 회차의 미사용 세차권 환불 (마지막 결제 회차만이 아님). 회차별로 일부 사용이 있는 경우 사용분은 1회성 상품 정상가 기준 차감. 세부 기준은 「예약 취소 및 환불 규정」 참조

**일시 정지**
- 정지 기간 중 기존 세차권 사용 가능
- 설정한 정지 기간이 종료되면 자동으로 구독 재개
- 정지 기간 중 조기 재개를 원하는 경우 → 아래 두 가지 방법 중 선택
  - 셀프 처리: 기존 구독 해지 후 동일 상품 재구매 → 즉시 결제와 함께 구독 재개 (조기 재개와 동일 효과). 잔여 세차권이 있다면 \[세차권 다음에 사용하기\] 선택 권장 — 환불 선택 시 사용분이 1회권 정상가 기준 차감되어 환불 금액 불리
  - 담당자 처리: CS로 문의 접수, 아래 내부 처리 절차 적용

## 내부 처리 절차 (정지 기간 중 조기 재개 요청 시에만 해당)
1. 고객으로부터 조기 재개 요청 접수, 구독 재개 희망일 탐색
2. 어드민에서 해당 구독 상품의 다음 결제일을 고객의 재개 희망일로 변경한다. (단, 당일 오후 12시 이전 변경 시 당일에 바로 결제가 진행되지만, 당일 오후 12시 이후 변경 시 익일에 결제가 진행된다 → 구독 정기 결제 배치 스케줄이 매일 오후 12시이기 때문)

## 고객 안내 문구

**해지·일시 정지 방법 문의 시**
> 구독 해지 / 일시 정지 방법에 대해 안내드립니다.
> 카라멜 앱 → 좌측 하단 \[내 차고\] 탭 → (차량이 여러 대인 경우) 상단에서 해당 차량 선택 → 우측 상단의 (구독상품명) 구독중> 버튼을 선택해 주세요.
>
> 구독 관리 페이지에서 \[해지\] 버튼을 누르시면 아래 두 가지 옵션을 선택하실 수 있습니다.
>
> 1. 구독 취소: 구독을 즉시 해지합니다.
>    - **\[세차권 다음에 사용하기\]**: 세차권을 일부라도 사용하신 상태라면 이 옵션이 더 유리합니다.
>    - **\[세차권 환불 받기\]**: 구독 기간 전체에서 미사용 세차권을 환불받으실 수 있습니다.
>
> 2. 일시 정지: 구독 결제를 일시적으로 멈춥니다. 정지 기간은 1개월 / 2개월 / 3개월 / 4개월 중 선택하실 수 있습니다.

**조기 재개 요청 시**
> 구독 일시정지 기간 중 조기 재개를 원하신다면 아래 두 가지 방법 중 선택하실 수 있습니다.
>
> \[방법 1. 셀프 처리\]
> 기존 구독을 해지하신 후 동일한 상품을 재구매하시면 즉시 결제와 함께 구독이 시작되어 조기 재개와 동일한 효과를 보실 수 있습니다.
> 잔여 세차권이 있으신 경우, 조기 재개가 목적이시라면 \[세차권 다음에 사용하기\]를 권장드립니다.
>
> \[방법 2. 담당자 처리\]
> 아래 내용을 이 채널에 남겨주시면 담당자가 직접 처리해 드립니다.
> ① 고객님 성함 및 연락처
> ② 재개 희망 날짜
> 오후 12시 이전 요청 시 당일부터, 이후 요청 시 익일부터 결제와 함께 재개됩니다.
