## 요약
리뷰에 번호판 등 개인정보가 노출된 사진 삭제를 요청하는 고객 문의 처리 기준. DB에서 직접 review_image 레코드를 소프트 삭제한다.

## 적용 조건
- 대상 고객: 전체
- 적용 상황: 고객이 리뷰에 올린 사진에 번호판 등이 노출되어 삭제를 요청하는 경우
- 적용 기간: 상시

## CS 처리 기준
1. 채널톡 프로필 또는 고객 메시지에서 예약 ID 확인
1. DB 조회로 이미지 목록 확인 (mysql-query.sh):
```sql
SELECT ri.id, ri.image_url
FROM review r
JOIN review_image ri ON r.id = ri.review_id
WHERE r.reservation_id = {예약ID}
  AND ri.deleted_yn = 0;
```
1. 삭제할 이미지 ID 확인 후 소프트 삭제 (mysql-write.sh 사용):
```sql
UPDATE review_image SET deleted_yn = 1 WHERE id = {이미지ID};
```
이미지가 여러 장이면: WHERE id IN (id1, id2, ...)
