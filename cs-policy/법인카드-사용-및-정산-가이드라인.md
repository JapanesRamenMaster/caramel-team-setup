## 요약
법인카드 사용 원칙, 고위드 앱 내역 등록 방법, 대금 결제 규정.

## 적용 조건
- 대상: 법인카드(고위드) 발급자 전체
- 적용 상황: 법인카드 이용 전반

## 상세 내용

### 사용 원칙
- 법인카드는 업무 목적(주차, 주유, 통행료 등)에만 사용
- 개인 목적 사용 금지 (가족 식사, 개인 물품 구매 등)

### 고위드 앱 내역 등록 (필수)
카드 사용 후 고위드 앱에서 해당 내역에 영수증과 목적을 등록해야 한다.
- 미등록 건은 미승인 처리 → 급여 지급 시 미포함
- 등록 기한: 카드 사용일로부터 7일 이내 권장, 늦어도 월말까지
- 반려된 내역은 재제출하거나 오퍼레이션 매니저에게 문의

### 대금 결제
- 결제일: 매월 15일 (주말·공휴일 시 다음 영업일)
- 결제 방식: 이용자 청구 방식 (본인 계좌에서 자동 출금)
- 회사 지급 시점: 대금 결제일 당일 오전에 승인된 내역만 지급

### 연체 발생 시
연체 적용 기준일: 대금 결제일의 다음 영업일

| 상황 | 조치 |
|---|---|
| 1차 연체 | 카드 사용 정지 |
| 이용 재개 | 정지일로부터 1개월 후 다음 달 첫 영업일 |
| 재발 연체 | 카드 즉시 해지 + 인사상 불이익 |

카드 정지 기간 중 개인 카드 사용 시 → 부가세 제외 공급가액만 정산 (예: 10,000원 사용 → 9,091원 지급)

### 카드 분실·파손
- 즉시 오퍼레이션 매니저 및 경영지원 담당자에게 보고
- 신한카드 고객센터에 분실 신고 (분실 이후 부정 사용 건 책임)
