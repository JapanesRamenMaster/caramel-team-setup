## 요약
신규 가입 시 자동 지급되는 웰컴 쿠폰 종류 안내 및 만료 후 재발급 문의 응대 기준. 두 가지 문의 유형(가입 혜택 확인 / 만료 재발급 요청)을 함께 다룬다.

## 적용 조건
- 대상 고객: 전체
- 적용 상황: 가입 시 지급된 웰컴 쿠폰 내용 문의, 또는 만료 후 재발급 요청
- 적용 기간: 상시

## CS 처리 기준

### 웰컴 쿠폰 종류 및 유효기간
가입 시 자동 발급 (유효기간 가입 후 3일):
- [웰컴 할인] 방문 세차 20% 할인
- [웰컴 할인] 프리미엄 왁스 코팅 2만원 할인
- [웰컴 할인] 유막 제거 / 발수 코팅 1만원 할인
- [웰컴 할인] 부분 스크래치 교정 1만원 할인
- [웰컴 할인] 차량 전체 살균 1만원 할인
- [웰컴 할인] 무광 왁스 코팅 2만원 할인
- [웰컴 할인] PPF 왁스 코팅 2만원 할인

### 케이스 1: 1차 안내 (원칙)
만료된 웰컴 쿠폰은 재발급 불가 안내 → 아래 고객 안내 문구 사용

### 케이스 2: 구독 상품 쿠폰 적용 문의
방문 세차 20% 할인 쿠폰은 세차 1회권 예약에만 적용 가능합니다. 구독 상품에는 이미 상시 할인이 적용되어 있어 중복 적용이 불가합니다.
→ 아래 고객 안내 문구(구독 적용 불가) 사용

### 케이스 3: 미수긍 시 예외 재발급
다음 조건 모두 충족 시에만 예외 재발급 가능:
- 예약 이력 없음 (첫 예약 전 고객)
- CS 판단 상 합리적인 사유
예약 이력 확인 방법 (mysql-query.sh):
```sql
SELECT COUNT(*) AS 예약건수
FROM reservation
WHERE user_id = {유저ID}
  AND deleted_yn = 0;
```
→ 예약건수 > 0이면 재발급 불가
재발급 실행: /coupon-grant 스킬 사용

## 고객 안내 문구

### 1차 안내 (불가)
안녕하세요, 카라멜입니다. 신규 가입 시 지급되는 웰컴 쿠폰은 가입 후 3일 이내 사용 가능한 쿠폰으로, 유효기간이 만료된 쿠폰은 재발급이 어렵습니다. 양해 부탁드립니다.

### 구독 상품 쿠폰 적용 불가 안내
안녕하세요 고객님! 카라멜 차량관리 서비스입니다.
신규 가입 시 지급되는 첫 세차 20% 할인권(발급일로부터 3일간 유효)은 세차 1회권 예약 시에만 적용이 가능한 상품입니다. 현재 확인하신 구독 상품들의 경우, 이미 상시로 큰 폭의 할인이 적용되어 있어 아쉽게도 추가 할인 혜택 중복 적용이 어려운 점 너그러운 양해 부탁드립니다.

## 내부 처리 절차
- 예외 재발급 시 /coupon-grant 스킬로 해당 쿠폰 재지급
- 재발급 시 채널톡 메모에 사유 기록
