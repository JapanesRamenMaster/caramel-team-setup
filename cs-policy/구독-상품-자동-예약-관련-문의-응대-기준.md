## 요약
구독 고객이 자동 예약 생성 이유 또는 자동 예약 비활성화를 문의할 때의 응대 기준.

## 적용 조건
- 대상 고객: 구독 고객 (월 2회 외부 / 월 4회 외부)
- 적용 상황: 자동 예약이 생성된 이유를 문의하거나, 자동 예약 기능을 끄고 싶다고 요청하는 경우
- 적용 기간: 상시

## CS 처리 기준
| 구독 상품 | 자동 예약 여부 | 생성 주기 |
| --- | --- | --- |
| 월 1회 (내부+외부) | 없음 (고객이 매월 직접 예약) | — |
| 월 2회 (외부) | 있음 | 첫 예약 일자 기준 2주 간격 |
| 월 4회 (외부) | 있음 | 첫 예약 일자 기준 1주 간격 |
- 자동 예약 비활성화 기능: 앱 내 제공하지 않음. 원하지 않는 예약은 전일 오후 8시 이전에 직접 취소 안내.
- 자동 예약 변경/취소: 일반 예약과 동일하게 앱에서 직접 처리 가능. 예약 전일 오후 8시 이전까지 변경/취소 가능.

## 고객 안내 문구

### 자동 예약이 왜 잡혀있냐고 문의하는 경우
고객님, 문의 주셔서 감사합니다.
카라멜은 구독 고객님께 원하시는 날짜와 시간에 안정적으로 세차를 받으실 수 있도록 자동 예약 서비스를 운영하고 있습니다. 저희 서비스 특성상 원하시는 일정이 빠르게 선점되는 경우가 많아, 자동으로 예약을 잡아드리지 않으면 원하시는 날짜와 시간에 예약이 어려울 수 있습니다.
[월 2회 외부 구독 고객]
고객님의 구독 상품은 첫 예약 일자를 기준으로 2주 간격으로 자동 예약이 생성됩니다.
[월 4회 외부 구독 고객]
고객님의 구독 상품은 첫 예약 일자를 기준으로 1주 간격으로 자동 예약이 생성됩니다.
자동으로 생성된 예약도 예약 전날 오후 8시 이전이라면 언제든지 변경하거나 취소하실 수 있으니, 일정이 맞지 않으시는 경우 자유롭게 조정해 주시면 됩니다.

### 자동 예약을 끄고 싶다고 요청하는 경우
고객님, 문의 주셔서 감사합니다.
현재 앱 내에서 자동 예약을 비활성화하는 기능은 제공되지 않습니다. 양해 부탁드립니다.
자동 예약은 저희 서비스 일정이 빠르게 선점되는 경우가 많아, 고객님이 원하시는 날짜에 세차를 받으실 수 있도록 미리 자리를 확보해 드리는 목적으로 운영되고 있습니다. 자동 예약이 잡혀있더라도 예약 전날 오후 8시 이전에는 언제든지 취소하실 수 있어 고객님께 별도의 불이익은 없습니다.
원하지 않으시는 예약은 예약 전날 오후 8시 이전에 취소해 주시면 되고, 취소 시 전액 환불 혹은 세차권이 복구되니 걱정 없이 이용해 주세요.
취소 방법: 카라멜 앱 → 좌측 하단 [내 차고] 탭 → 해당 예약 하단 [예약 변경/취소]
