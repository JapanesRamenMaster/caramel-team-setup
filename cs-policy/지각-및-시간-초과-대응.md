## 요약
디테일러가 늦거나, 고객이 늦을 때의 대응 절차.

## 적용 조건
- 대상: 디테일러 전체
- 적용 상황: 지각 또는 시간 초과 발생 시

## 상세 내용

### 디테일러가 늦는 경우 (오버타임, 도로상황 등)
1. 다음 타임 고객에게 얼마나 늦을지 사전 안내 필수
  - 현재 세차의 대략적인 종료 시간 계산
  - 티맵에서 출발 예정 시간 설정하여 이동 소요 시간 계산
  - 다음 세차에 얼마나 늦게 될지 산출하여 고객 안내
1. 고객이 늦는 것에 불만 있으면 → 사과 + 왕스코팅 등 서비스 추가 제공
1. 고객이 취소를 원하면 → 사과 + 옵션 서비스 추가 + 다른 시간대 재예약 안내
  - #caramel_realtime에 반드시 오퍼레이션 매니저 태그 후 공유
  - 전후 상황과 고객 반응을 상세히 기록
1. 30분 이상 과도하게 늦어질 경우 → #caramel_realtime 통해 회사에 알리기

### 고객이 늦는 경우 / 키를 늦게 인계한 경우
다음 타임에 세차 예약이 있는 경우:
| 지연 시간 | 대응 |
| --- | --- |
| 15분 미만 | 예정대로 세차 진행 |
| 15분~30분 | 외부 또는 내부 중 하나가 미흡할 수 있음 안내. 고객에게 어느 쪽을 신경 써달라는지 문의 후 진행 |
| 30분~1시간 | 외부와 내부 중 한 가지만 진행 가능함 안내. 고객에게 선택 요구 |
| 1시간 초과 | 노쇼 처리 |
다음 타임에 세차 예약이 없는 경우:
- 예정대로 세차 진행하고 생색내기 → 만족도 높이고 컴플레인 방지

## 보고 방법
- 30분 이상 지각 시 #caramel_realtime에 보고
- 고객 취소 시 오퍼레이션 매니저 태그 후 공유
