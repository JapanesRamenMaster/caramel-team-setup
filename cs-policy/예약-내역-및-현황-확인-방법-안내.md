## 요약
고객이 예약 현황 또는 예약 내역 확인 방법을 문의할 때 앱 내 경로를 안내합니다.

## 적용 조건
- 대상 고객: 전체
- 적용 상황: 앱에서 예약 현황 또는 예약 내역 확인 방법을 문의하는 경우
- 적용 기간: 상시

## CS 처리 기준
문의 유형에 따라 안내 경로가 다름.
| 문의 유형 | 안내 경로 |
| --- | --- |
| 예정된 예약 현황 확인 | 좌측 하단 [내 차고] 탭 → [예정된 세차] |
| 전체 예약 내역 확인 (지난 예약 포함) | 우측 하단 [마이] 탭 → 좌측 상단 [이용내역] |

## 고객 안내 문구
안녕하세요, 고객님!
카라멜 고객서비스 팀입니다.
예약 현황 및 내역은 아래 두 가지 경로로 확인하실 수 있습니다.
예정된 예약 확인
카라멜 앱 → 좌측 하단 [내 차고] 탭 → [예정된 세차] 탭
전체 예약 내역 확인 (지난 예약 포함)
카라멜 앱 → 우측 하단 [마이] 탭 → 좌측 상단 [이용내역]
여러 차량을 등록하신 경우, [내 차고] 탭 화면 상단에서 확인하실 차량을 먼저 선택해 주세요.
추가로 궁금하신 점이 있다면 언제든 말씀해 주세요.
