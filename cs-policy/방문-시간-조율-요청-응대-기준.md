## 요약
예약 시간보다 일찍 또는 늦게 방문 시간을 조율하고자 하는 고객에게 처리 기준을 안내한다. 앱 예약 변경과는 별개의 케이스다.

## 적용 조건
- 대상 고객: 전체 (1회·구독 공통)
- 적용 상황: 예약 시간보다 일찍/늦게 방문 시간 직접 조율 요청 (예: "12시 예약인데 11시에 와주실 수 있어요?")
- 적용 기간: 상시
- ⚠️ 예약 날짜·시간 슬롯 변경 문의는 「예약 일정 변경 문의 응대 기준」 문서 참조

## CS 처리 기준
| 문의 유형 | CS 처리 |
| --- | --- |
| 방문 시간 앞당기기/늦추기 조율 요청 (앱 슬롯 변경 아님) | 2시간 단위 슬롯 외 임의 시간 변경 불가 안내 → 전일 저녁 담당 디테일러 연락 시 직접 조율 가능성 안내 (확답 불가, 원칙은 정시 시작) |
원칙:
- 예약 슬롯은 2시간 단위 고정 운영(예: 8시, 10시, 12시, 14시…)이며, 슬롯 사이 임의 시간(예: 11시, 11시 30분)으로의 시간 조정은 시스템상 불가하다.
- CS가 시간을 직접 조율하거나 보장하지 않는다.

## 내부 처리 절차
별도 내부 액션 없음. 고객 안내 후 종결.

## 예외 사항
- 방문 시간 변경은 원칙적으로 불가하다. 다만 예약을 유지한 채 방문 시간을 디테일러와 직접 조율하는 것은 앱 슬롯 변경과 별개 케이스로, CS는 전일 디테일러 연락 시 조율 가능성만 안내한다. 실제 조율 가능 여부는 당일 이동 동선 및 다른 고객 예약 상황에 따라 달라지므로 CS가 보장하지 않는다.
