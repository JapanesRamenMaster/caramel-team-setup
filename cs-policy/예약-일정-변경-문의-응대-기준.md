## 요약
고객이 이미 예약한 세차의 방문 일정을 변경하는 방법을 안내합니다.

## 적용 조건
- 대상 고객: 전체 (1회/구독 공통)
- 적용 상황: 예약 완료 후 방문 일정을 변경하려는 경우
- 적용 기간: 상시

## CS 처리 기준
| 변경 요청 시점 | 처리 방법 |
| --- | --- |
| 예약 전일 오후 8시 이전 | 고객이 직접 앱에서 변경 가능 |
| 예약 전일 오후 8시 이후 | 일정 변경 불가 — 취소만 가능 (취소 패널티 발생, 「예약 당일 취소 시 환불 기준」 문서 참조) |

## 고객 안내 문구
예약 일정 변경은 예약 전날 오후 8시까지 고객님께서 직접 진행하실 수 있습니다.
변경 방법은 두 가지입니다.
카라멜 앱 실행 → 좌측 하단 [내 차고] 탭 → 변경하려는 예약 하단의 [예약 변경/취소] 버튼 선택

## 내부 처리 절차
- 일정 변경은 고객이 직접 진행하며, CS 담당자 개입 없음
- 변경 완료 시 고객에게 카카오톡 알림톡 자동 발송됨 (차량 정보, 방문 일정, 방문 장소, 예약 상품명 포함)
- 전일 오후 8시 이후 변경 문의가 오는 경우: 변경 불가 안내 후, 취소를 원하면 「예약 취소 및 환불 규정」 문서에 따라 취소 가능 여부와 취소 조건 안내
