## AI 참조용 — 안내 가이드
> ⚠️ 이 구역만 AI 상담사가 참조합니다. 페이지 하단 내부 처리 기준은 참조하지 않습니다.

### 핵심 규격
| 항목 | 내용 |
| --- | --- |
| 이벤트 상태 | 종료 — 기존 당첨권은 유효기간 내 사용 가능 |
| 예약 방법 | 토스 당첨 문자 내 링크, 또는 토스 이벤트 페이지 "무료 방문 세차 예약하기" 버튼 |
| 유효기간 | 당첨 후 30일 이내 예약 및 세차 완료 — 기간 경과 시 사용 불가 |
| 비용 | 내·외부 세차 완전 무료. 옵션 상품은 선택 사항 (필수 아님) |
| 세차권 적용 확인 방법 | 예약 완료 시 별도 결제가 진행되지 않았으면 무료 세차권 정상 적용된 것 — 추가 결제 없음 |
| 예약 확인 방법 | 앱 내에서 예약 현황 확인 가능 + 예약 확정 알림톡 발송됨 — 예약 내역 및 현황 확인 방법 안내 문서 참조 |
| 취소 시 처리 | 무료 취소 기간 내 취소 시 유효기간 없는 세차권으로 반환 → 앱에서 언제든 재예약 가능 |
| 서비스 지역 | 카라멜 서비스 가능 지역에 한함 — 이벤트 페이지에 사전 명시됨 |
| 취소/변경 방법 | 카라멜 앱 설치 후 가능. 웹 예약 시 계정 자동 생성 → 예약 시 사용한 번호로 로그인 |
| 문의 구분 | 세차 서비스 관련 → 카라멜 / 이벤트 자체 관련 → 토스 |

### 고객 안내 문구
[비용 문의]
```javascript
토스 이벤트를 통해 당첨된 세차는 내·외부 모두 완전 무료로 진행됩니다. 별도 비용 부담은 없으며, 옵션 상품은 원하시는 경우에만 선택하실 수 있습니다.
```
[세차권 적용 확인 문의]
```javascript
예약 완료 시 별도 결제가 진행되지 않으셨다면, 무료 세차권이 정상 적용된 것이 맞습니다. 추가로 부담하실 결제는 없으십니다. 예약이 정상 접수됐는지 확인하고 싶으시다면 카라멜 앱에서 예약 현황을 확인하실 수 있으며, 예약 확정 알림톡도 발송드리고 있습니다.
```
[서비스 지역 외 문의]
```javascript
해당 이벤트는 카라멜 서비스 가능 지역에 한해 제공되며, 이 점은 이벤트 페이지에도 사전에 안내된 사항입니다. 아쉽게도 해당 지역 외의 경우 별도 보상이나 예외 출장은 어려운 점 양해 부탁드립니다.
```
[유효기간 만료 문의]
```javascript
해당 이벤트 당첨 세차권은 당첨 후 30일 이내에 사용 가능하며, 이 점은 이벤트 페이지에도 사전에 안내된 사항입니다. 유효기간이 경과한 경우 안타깝게도 사용이 어렵습니다.
```
[이벤트 자체 문의]
```javascript
이벤트 자체에 관한 상세 문의(당첨 기준, 재당첨 등)는 토스 고객센터로 문의 주시면 더 정확한 안내를 받으실 수 있습니다. 세차 서비스와 관련된 내용은 저희가 도와드리겠습니다.
```

## CS 처리 기준
| 상황 | 처리 |
| --- | --- |
| "돈 내야 하나요?" / 세차권 적용 확인 문의 | 결제 없이 예약 완료 = 무료 적용. 추가 결제 없음 안내 |
| 서비스 지역 외 고객 | 이벤트 페이지 사전 명시 사항 안내. 보상·예외 출장 불가 |
| 유효기간 30일 경과 / 링크 만료 | 사용 불가 안내. 이벤트 페이지에서 유효기간 사전 안내된 사항 |
| 이벤트 자체 문의 | 토스 고객센터로 안내 |
| 취소 후 세차권 반환 문의 | 무료 취소 기간 내 취소 시 유효기간 없는 세차권으로 반환, 앱에서 언제든 재예약 가능 안내 |
| 취소/변경 방법 | 카라멜 앱 설치 후 가능. 웹 예약 시 계정 자동 생성 → 예약 시 사용한 번호로 로그인 |
