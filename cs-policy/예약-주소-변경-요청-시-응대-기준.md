## 요약
고객이 세차 방문 주소 변경을 요청하는 경우, 카라멜 앱에서 직접 변경 가능하도록 안내한다. 기존 예약 건 변경과 신규 예약 시 주소 변경 두 가지 경우로 나뉜다.

## 적용 조건
- 대상 고객: 전체 (1회 세차 / 구독 세차 공통)
- 적용 상황: 고객이 방문 주소 변경을 요청하는 경우
- 적용 기간: 상시

## CS 처리 기준

### 케이스 1. 기존 예약 건의 주소 변경
카라멜 앱 실행 → 좌측 하단 [내 차고] 탭 → 예약 내역에서 [예약 변경/취소] → [방문 주소 변경]

### 케이스 2. 신규 예약 시 주소 변경
카라멜 앱 실행 → 좌측 하단 [내 차고] 탭 → 일정 선택 캘린더 위 주소란의 우측 [수정] 버튼 (연필 아이콘) 클릭 후 주소 선택
> 기존 등록된 주소록에 없는 신규 주소는 해당 화면 하단의 [새로운 주소 추가하기]로 추가 가능

## 예외 사항
- 주소 변경 가능 데드라인은 예약일 전일 오후 8시까지 앱을 통해 변경 가능
- 단, 기존 예약 주소지와 거리가 먼 곳으로 변경하는 경우, 예약일에 임박하여 변경 시 디테일러 동선을 급작스레 변경하기 어려워 방문이 어려워질 수 있음 → 시간 여유를 두고 변경하도록 권장 (케이스 1 해당)

## 고객 안내 문구
케이스 1. 기존 예약 건 주소 변경
안녕하세요, 고객님. 카라멜입니다.
방문 주소 변경은 카라멜 앱에서 직접 변경하실 수 있습니다.
카라멜 앱 실행 → 좌측 하단 [내 차고] 탭 → 예약 내역에서 [예약 변경/취소] → [방문 주소 변경]
다만, 기존 주소지와 거리가 먼 곳으로 변경하시는 경우 예약일에 임박하여 변경하시면 디테일러 동선 변경이 어려워 방문이 어려운 경우가 있습니다.
사전에 시간 여유를 두고 변경해 주시면 감사하겠습니다.
추가 문의 사항이 있으시면 언제든지 말씀해 주세요.
케이스 2. 신규 예약 시 주소 변경
안녕하세요, 고객님. 카라멜입니다.
신규 예약 시 방문 주소 변경은 아래와 같이 진행해 주세요.
카라멜 앱 실행 → 좌측 하단 [내 차고] 탭 → 일정 선택 캘린더 위 주소란의 우측 [수정] 버튼 (연필 아이콘) 클릭 후 주소 선택
기존 등록하신 주소록에 없는 새로운 주소는 해당 화면 하단의 [새로운 주소 추가하기]를 통해 추가하실 수 있습니다.
추가 문의 사항이 있으시면 언제든지 말씀해 주세요.
