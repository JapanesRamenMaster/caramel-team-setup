## 요약
포인트 적립 방법, 유효기간 확인, 사용 방법에 관한 고객 문의 응대 기준 및 내부 처리 절차.

## 적용 조건
- 대상 고객: 전체 (1회 세차 / 구독 세차 공통)
- 적용 상황: 포인트 적립·유효기간·사용 방법 관련 고객 문의 발생 시
- 적용 기간: 상시

## CS 처리 기준

### 1. 포인트 적립 방법
| 적립 유형 | 적립 조건 | 적립 금액 | 유효기간 |
| --- | --- | --- | --- |
| 리뷰 적립 | 서비스 이용 후 앱에서 리뷰 작성 | 3,000포인트 | 적립일로부터 3개월 |
| 어드민 임의 적립 | 카라멜 측 어드민을 통해 지급 | 건별 상이 | 건별 상이 (지급 시 설정) |
- 포인트 적립 시 고객에게 알림톡 자동 발송됨
- 알림톡 표시 내용: 적립 포인트, 적립 사유, 적립 금액, 유효기간

### 2. 포인트 유효기간 문의
1단계 — 고객에게 안내
- 먼저 고객에게 적립 사유 확인 (리뷰 적립인지, 카라멜 측 제공인지)
- 리뷰 적립인 경우: 적립일로부터 3개월임을 안내
- 카라멜 측 제공인 경우: 유효기간이 건별로 다를 수 있으므로, 포인트 적립 시 수신한 알림톡을 통해 확인 요청
- 적립 사유가 불명확한 경우: 알림톡 확인 요청 (알림톡에 적립 사유·유효기간 모두 표시됨)
2단계 — 고객이 직접 확인 어렵다며 CS에 확인 요청하는 경우
- 어드민에서 해당 고객의 알림톡 발송 내역 조회하여 확인
- 어드민 조회로도 확인 어려운 경우 → CS 슬랙 채널에서 dev팀 태그하여 확인 요청

### 3. 포인트 사용 방법
자동 사용 옵션 설정
- 경로: 카라멜 앱 → 우측 하단 [마이] 탭 → 포인트 → [결제 시 포인트 자동 사용 옵션]
- 기본값: 활성화
- 활성화 시: 구독 갱신 자동결제 시 보유 포인트 우선 자동 차감 후 차액 결제
결제 화면에서 포인트 적용/미적용 선택 가능한 경우
| 결제 유형 | 포인트 적용 방식 |
| --- | --- |
| 구독 상품 최초 구매 | 결제 화면에서 적용/미적용 선택 가능 |
| 1회 이용권 구매 | 결제 화면에서 적용/미적용 선택 가능 |
| 기존 예약에 옵션 추가 결제 | 결제 화면에서 적용/미적용 선택 가능 |
- 결제 화면 기본값: 자동 사용 옵션 활성화 상태이면 보유 포인트 전액 적용된 상태로 표시
- 포인트 미적용 원할 시: 결제 화면 포인트 란 우측 [취소] 버튼 클릭
기타
- 쿠폰 보유 시 포인트와 중복 사용 가능
문의 유형별 응대 예시
① 구독 갱신/자동결제 시 포인트 적용 방법 문의
> 고객: "구독 자동결제할 때 포인트를 사용하고 싶은데 어떻게 하나요?"
응대:
> 안녕하세요, 고객님. 카라멜 앱 → 우측 하단 [마이] 탭 → 포인트에서 [결제 시 포인트 자동 사용 옵션]이 활성화되어 있으면, 구독 갱신 자동결제 시 보유하신 포인트가 자동으로 차감된 후 차액이 결제됩니다. 기본값이 활성화 상태이므로, 해당 옵션이 켜져 있는지 앱에서 확인해 주시면 됩니다.
② 구독 자동결제 시 포인트가 적용되지 않았다는 문의
> 고객: "포인트가 있는데 자동결제할 때 차감이 안 됐어요."
응대 순서:
1. 결제일 당시 포인트 잔액이 있었는지 확인 요청 (결제 이후 사후 적립된 건 아닌지)
1. 앱에서 [결제 시 포인트 자동 사용 옵션] 활성화 여부 확인 요청 (경로 안내)
> 안녕하세요, 고객님. 두 가지 확인 부탁드립니다. 첫째, 결제일 당시 포인트 잔액이 있으셨는지 확인해 주세요. 결제 이후 적립되신 경우 해당 회차에는 적용되지 않습니다. 둘째, 카라멜 앱 → 우측 하단 [마이] 탭 → 포인트에서 [결제 시 포인트 자동 사용 옵션]이 활성화되어 있는지 확인해 주세요.
③ 결제 화면에서 포인트 적용/미적용 방법 문의
> 고객: "결제할 때 포인트를 빼고 결제하고 싶어요." / "결제 화면에서 포인트 적용하는 방법이 어떻게 되나요?"
응대:
> 안녕하세요, 고객님. 구독 상품 최초 구매, 1회 이용권 구매, 옵션 추가 결제 시 결제 화면에서 포인트 적용 여부를 선택하실 수 있습니다. 기본적으로 보유하신 포인트가 적용된 상태로 표시되며, 포인트를 사용하지 않으시려면 결제 화면의 포인트 란 우측 [취소] 버튼을 눌러 주시면 됩니다.

## 고객 안내 문구
유효기간 문의 시 (1차 안내)
안녕하세요, 고객님. 포인트 유효기간은 리뷰 작성으로 적립된 경우 적립일로부터 3개월입니다. 정확한 유효기간은 포인트 적립 시 수신하신 알림톡에서 확인하실 수 있습니다.
포인트 자동 사용 해제 안내 시
포인트 자동 사용을 해제하시려면 카라멜 앱 → 우측 하단 [마이] 탭 → 포인트에서 [결제 시 포인트 자동 사용 옵션]을 비활성화해 주시면 됩니다.

## 내부 처리 절차
- 고객이 유효기간 직접 확인 요청 시: 어드민에서 알림톡 발송 내역 우선 조회
- 어드민 조회 불가 시: CS 슬랙 채널에서 dev팀 태그 후 확인 요청
