## 요약
고객이 예약 시 선택하지 않은 옵션을 세차 당일 현장에서 추가할 수 있는지 문의하는 경우의 응대 기준. 현장 추가는 세차 종료 전까지 가능하며, 앱에서 보이지 않는 현장 전용 옵션 4개도 별도로 안내한다.

## 적용 조건
- 대상 고객: 전체
- 적용 상황: 현장에서 옵션 추가 가능 여부 문의 인입 시
- 적용 기간: 상시

## CS 처리 기준
추가 가능 시점
세차 종료 전까지 추가 가능 (작업 시작 후도 가능). 단, 예약 시 미리 선택한 옵션은 디테일러가 작업 시간·동선을 사전 조율하므로, 현장에서 갑작스럽게 추가하면 시간 상 진행이 어려울 수 있음. 이 경우 디테일러가 직접 양해 요청.
앱에 노출되지 않는 현장 전용 옵션
실제 작업 가능 여부를 현장에서 직접 확인해야 하는 특성상 앱에 노출하지 않음. 디테일러가 예약 전일 연락 시 미리 요청하거나, 현장에서 디테일러가 필요하다고 판단 시 추천.
| 옵션 | 가격 | 시공 방법 | 주의사항 |
| --- | --- | --- | --- |
| 송진 제거 | 개당 10,000원 | 전문 케미컬 우선 적용 → 제거 어려운 경우 연마제+연마기기 부분 사용 |  |
| 스티커 제거 | 개당 10,000원 | 스팀기 가열 또는 전용 케미컬 사용 | 오염 종류에 따라 작업 불가한 경우 있음. 정확한 가능 여부는 디테일러가 현장에서 최종 판단 |
| 석회수 제거 | 판당 50,000원 | 전문 케미컬+광택기로 도장면 바깥을 연마하여 제거. 판 = 차량 외관을 구성하는 각 패널(부위) 1개 (예: 본넷, 도어 한 짝, 펜더, 트렁크, 루프 등) | 오염 발생 후 시간이 경과된 경우 도장면 내부까지 이염되어 완벽 제거 불가. 해당 부분은 재도색이 필요한 케이스로 타 업체도 동일 |
| 탈취캔 | 30,000원 | 전문 탈취 제품 사용. 분사 성분이 차량 내부와 공조 시스템 전체를 순환하며 냄새 입자 분해+유해균 제거 | 시공 직후 일정 기간 제품 냄새 강할 수 있음 — 고객에게 사전 안내 필요 |
현장 결제 방법
| 방법 | 비고 |
| --- | --- |
| 온라인 결제 링크 | 디테일러가 고객에게 링크 전송 |
| 법인 계좌 입금 | 현금영수증 발행 가능 |
| 현장 카드 단말기 | 디테일러 소지 단말기로 결제 |

## 고객 안내 문구
현장 옵션 추가 가능 여부 문의 시 (공통)
> 네, 세차 종료 전까지 현장에서 언제든 옵션 추가가 가능합니다. 작업 시작 후라도 추가하실 수 있으니 디테일러에게 직접 말씀해 주시면 됩니다.
앱에 없는 현장 전용 옵션 문의 시
> 앱 예약 화면에는 보이지 않지만 현장에서 추가 가능한 옵션도 있습니다. 차량 상태를 직접 확인해야 작업 가능 여부를 판단할 수 있는 옵션들로, 디테일러가 예약 전날 연락드릴 때 미리 말씀해 주시거나 현장에서 요청해 주시면 됩니다.
