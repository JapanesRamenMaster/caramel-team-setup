## 요약
내부 스팀 추가 옵션 문의 시 응대 기준. 스팀 청소는 찌든 때·컵홀더 오염 등 일반 내부 세차로 제거 어려운 부위에 스팀기를 사용하는 옵션으로, 내부 전체 청소가 아님을 사전 고지한다.

## 적용 조건
- 대상 고객: 전체
- 적용 상황: 내부 스팀 추가 옵션 내용 및 가격을 문의하는 경우
- 적용 기간: 상시
- 이용 조건: 내부 세차가 포함된 예약에서만 추가 가능 (외부+내부 세차 예약 또는 외부 세차에 내부 세차 추가 옵션을 함께 선택한 경우)

## CS 처리 기준
- 옵션 특성 설명 (부분 스팀 청소, 내부 전체 청소 아님) 안내
- 고객 목적에 따라 적합한 상품 안내
  - 내부 전체 청소 원하는 경우 → 외부+내부 예약 또는 내부 세차 추가 옵션 권유
  - 특정 부위 찌든 때 제거 원하는 경우 → 내부 스팀 추가 옵션 안내
- 가격: 40,000원 (차량 티어 무관 고정)

## 고객 안내 문구
※ 이 옵션은 내부 세차가 포함된 경우에만 추가 가능합니다. (외부+내부 세차 예약 또는 외부 세차에 내부 세차 추가 옵션을 함께 선택한 경우)
안녕하세요 고객님, 카라멜 차량관리 서비스입니다.
문의하신 '내부 스팀 추가' 옵션에 대해 안내해 드릴게요.
내부 스팀 추가는 내부의 찌든 때나 컵홀더의 음료 자국처럼 일반적인 내부 세차 공정으로는 제거하기 어려운 오염을 스팀기를 사용하여 불리고 제거하는 방식입니다.
내부 전체를 스팀 청소하는 서비스는 아닌 점 참고 부탁드려요.
만약 원하시는게 내부 세차 전반이라면, 다음 두 가지 방법을 추천해 드립니다:
1. 내부+외부 세차로 예약
1. 외부 세차만 예약하신 경우, '내부 스팀 추가'가 아닌 '내부 세차 추가' 옵션 선택
차량 상태에 맞춰 필요한 옵션을 선택해 주시면 꼼꼼하게 관리해 드리겠습니다.
내부 스팀 추가 옵션 가격은 40,000원입니다.
추가로 궁금한 점이 있으시면 언제든 말씀해 주세요!
