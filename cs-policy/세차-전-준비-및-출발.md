## 요약
세차 출발 전 준비해야 할 장비, 확인 사항, 보고 방법.

## 적용 조건
- 대상: 디테일러 전체
- 적용 상황: 매 영업일 세차 시작 전

## 상세 내용

### 출발 전 확인 체크리스트
- [ ] 디테일러 웹에서 당일 예약 목록 확인
- [ ] 세차 장비 전체 탑재 확인
  - 고압세척기 (수압 정상 여부)
  - 청소 도구 (브러시, 걸레, 스펀지 등)
  - 케미컬 (세차 약품, 코팅 재료 등)
  - 페이히어 단말기 (배터리 충전 상태)
- [ ] 차량 주유 상태 확인 (잔량 25% 미만 시 출발 전 주유)
- [ ] 복장 확인 (유니폼 착용 완료)
- [ ] 출발 보고 (슬랙 채널)

### 출발 보고
- 채널: #caramel_realtime 또는 지정된 셀 채널
- 보고 내용: 출발 시간 + 첫 번째 예약 고객 위치 (동 단위)

### 장비 이상 발견 시
- 출발 전 발견 시: 즉시 오퍼레이션 매니저에게 보고, 대체 장비 여부 확인 후 출발
- 현장 도착 후 발견 시: 오퍼레이션 매니저에게 보고, 가능 범위 내 작업 후 고객 상황 안내

### 케미컬·소모품 보충 기준
- 세차 완료 건 기준 : 하루 예상 건수 기준 여유분 20% 이상 유지
- 부족 발견 시 다음 날 업무 전 보충, 오퍼레이션 매니저에게 보고
