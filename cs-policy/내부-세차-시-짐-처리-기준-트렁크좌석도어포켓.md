## 요약
내부 세차 또는 올클린(내·외부) 세차 진행 시, 짐의 위치·수량에 따라 청소 방식이 달라집니다. 트렁크 짐은 수량 기준(10개)이 적용되며, 뒷좌석·앞좌석·도어포켓 짐은 디테일러가 세차 전 임시 이동 후 세차 완료 후 다시 정리해 드립니다.

## 적용 조건
- 대상 고객: 전체 (1회 · 구독 공통)
- 적용 상황: 내부 세차 또는 올클린 세차 진행 시 차량 내부(트렁크·뒷좌석·앞좌석·도어포켓)에 짐이 있는 경우
- 차량 구분: 공통 (수입차 · 국산차)
- 적용 기간: 상시

## 트렁크 짐 처리 기준
| 트렁크 짐 수량 | 처리 방식 |
| --- | --- |
| 10개 이하 | 짐을 모두 꺼낸 뒤 트렁크를 꼼꼼히 청소하고, 완료 후 다시 정리해 드림 |
| 10개 이하이나 부피·무게가 큰 경우 | 디테일러 현장 판단에 따라 부피, 무게가 과도하게 크다면 짐을 꺼내지 않고 진행할 수 도 있음, 이 경우 현장에서 디테일러가 고객에게 설명 및 직접 양해 구함 |
| 10개 초과 | 짐은 그대로 둔 상태에서 진공청소기·타월로 가능한 공간을 최대한 청소하고, 짐 정리 도움 |

## 좌석·도어포켓 짐 처리 기준
| 구역 | 처리 방식 |
| --- | --- |
| 뒷좌석·앞좌석 (시트 위 짐) | 수량 제한 없음. 세차 전 디테일러가 임시 이동 후 세차 완료 후 다시 정리해 드림. 단, 이동이 곤란하거나 크고 무거운 짐은 현장에서 디테일러가 고객에게 직접 안내 후 가능한 범위에서 청소 |
| 카시트 (그대로 있는 경우) | 카시트 주변 범위만 청소 (카시트 아래 미포함). 차량 내부에 카시트가 있는 부분은 제외하고 청소 진행 |
| 카시트 (고객이 차량 밖으로 완전히 빼놓은 경우) | 카시트가 있던 자리(시트 바닥·등받이) 청소 가능. 차량 안에서 분리만 해둔 상태는 불가 — 반드시 차량 밖으로 완전히 빼내야 함. 카시트 자체는 청소하지 않음 |
| 카시트 (케어 옵션 구매 시) | 디테일러가 직접 탈거 후 해당 자리 청소 (재장착은 고객 직접) |
| 도어 포켓 | 짐을 꺼낸 후 진공 청소, 세차 완료 후 다시 정리 |

## 고객 안내 문구
> [뒷좌석·앞좌석] 시트 위 짐이 있어도 세차에 지장 없습니다. 디테일러가 세차 전 짐을 임시로 옮겨두고 청소 완료 후 다시 정리해 드립니다. 다만 크고 무거운 짐은 현장 상황에 따라 디테일러가 직접 안내드릴 수 있습니다.
> [트렁크] 내부 세차 시 트렁크 청소에 대해 안내드립니다.
