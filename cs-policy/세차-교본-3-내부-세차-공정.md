## 요약
내부 세차 전 공정(STEP 6~11)을 다룬다. 짐 빼기에서 시작하여 청소기, 타월 작업, 매트 세철, 타이어 드레싱, 말벌(마무리 점검)까지 순서와 주의사항을 다룬다.

## 적용 조건
- 대상: 디테일러 전체
- 적용 상황: 외부 세차 완료 후 내부 세차 진행 시

## 상세 내용

### STEP 6. 짐 빼기
내부 세차 시작 전 고객 짐 정리 단계다.
- 뎷자리를 꺼내 펼다
- 매트를 모두 탈거하여 뎷자리 위에 올려놓는다 (예외 없음)
- 트렁크 → 뒷좌석 → 문 → 앞좌석 순으로 짐을 모두 빼다
- 짐을 다 빼지 않으면 습관적으로 빼지 않고 청소하게 됨 — 반드시 전부 제거하는 습관 들이기
- 운전석 문 짐 → 운전석 시트 위, 조수석 문 짐 → 조수석 시트 위로 임시 이동 가능
트렁크 열 때 주차장 덕트·배수구에 파손되는 경우 발생 — 반드시 손으로 잡고 열기.
---

### STEP 7. 문 틈새
외부 2차 닦아내기에 사용한 왁스 묻은 타월을 활용해 틈새 및 실내 하단부를 세철한다.
- 문이 열려야 보이는 부분이 틈새
- 틈새 닦으면서 실내 하단부 플라스틱 트림 가볍게 선 세철
- 실내 하단부 플라스틱을 미리 한 번 닦아두는 이유: 실내용 깨끗한 타월이 오염되는 것 방지, 코팅이 필요한지 여부 사전 판단
- 타월의 수분만으로 잘 안 닦이지면 외부2차케미컬(소분) 추가 도포하여 불려서 닦기
- 트렁크 리드도 틈새 범위에 포함
---

### STEP 8. 내부 세차
내부 세차 시작 전 실내등을 모두 끄다.
8-1. 청소기
- 끌지 말고 최대한 들고 다닌다 → 호스가 도장면에 닿으면 기스 발생
- 트렁크 청소 시 호스가 특히 많이 닿음 — 집중 주의
- 시트를 청소기로 문지르면 가죽 손상 → 툴툴 두드리며 누르면서 흥입
- 문지르면 안 되는 곳: 플라스틱 가니쉐, 투명 부분, 크롬, 검은 시트 → 자국 생김
- 청소기 작업 후 타월 작업 예정 — 타월로 제거 불가한 틈새 먼지(버튼·손잡이·창문 버튼 등) 청소기로 선제 제거
좌석별 청소기 순서 및 포인트
| 구역 | 세부 가이드 |
| --- | --- |
| 운전석 앞좌석 | 의자를 제일 뒤로 빼고 의자 아래 먼지 눈으로 확인 후 흥입. 의자·센터콘솔 사이 앙습호 흥입. 시트: 등받이-엉덩이 겨치는 부분, 안전벨트 버클 중심으로. 컵홀더, 콘솔박스, 대시보드, 센터페시아 흥입. 문 손잡이, 창문 버튼. B필러-의자 사이 청소 |
| 운전석 뒷좌석 | 앞좌석이 최전방인 상태에서 앞좌석 밑부터 매트 청소. 앞좌석 의자 아래 눈으로 보며 청소. 센터콘솔·앞좌석 사이 뒷부분 이때 청소. 좌석 아랫 부분 벽면 신경 쓰기. 뒷좌석 컵홀더·콘솔박스·쉬레기 (어린이 과자 부스러기 다수) |
| 트렁크 | 짐이 10묶음 이상이면 짐 드러내기 불가 → 안내 (드러내지 않고 청소기 및 타월작업은 꽔 해야 함). 내부 플라스틱 가니쉐 먼지 제거. 트렁크 문 플라스틱 가니쉐도 닦기 |
| 조수석 뒷좌석 / 앞좌석 | 운전석 해당 좌석과 동일 |
8-2. 타월 작업 (내부)
깨끗한 탈수된 맙타월 1장 + 깨끗한 마른 극세사 타월 1장을 준비한다. 맙타월로 작업 후 반드시 바로 마른 타월로 마무리한다 (잔사는 항상 남음).
케미컬 사용 원칙
| 케미컬 | 사용제 | 주의사항 |
| --- | --- | --- |
| 클린앤코트 (실내세정제) | 컵홀더, 플라스틱 트림, 색 바랜 부분 | 약한 코팅 성분 — 검정 플라스틱 색 복원 가능 |
| 매트레더코트 | 색 심하게 바랜 플라스틱 하단부 | 코팅 성분 강함 — 일부만 코팅하면 얼룩. 전체 균일하게 처리 필요. 타이어 전용 타월 사용 |
| 유리세정제 | 유리에 왁스 물은 경우 등 긴급 처리 | 암모니아 없는 제품만 사용 (선팅 손상 방지). 타월에만 듹릴 것 |
| 알콜 소독제 | 지문 다수 시 디스플레이·유리 | 소량 사용. 타월에만 도포 |
코트(왁스 성분 포함) 케미컬은 유리·디스플레이에 기름 자국을 남겨 제거가 매우 어렵다. 시트·플라스틱에 튀면 종이에 기름 번지듯 점박이 얼룩 발생. 반드시 타월에만 도포한다.
내부 타월 작업 주의사항
- 마른 타월을 최대한 젖지 않게 유지 → 마감 품질에 직결
- 땀이 떨어진 부분 → 맙타월로 반드시 닦기 (마른 타월로 닦으면 물자국 발생)
- 에어콘 송풍구·인테리어 틈새 → 맙타월 한 겹으로 얇게 폍서 타월만 넣어 닦기
- 발이 닿는 색 바랜 플라스틱 → 닦으려 하지 말고 바로 매트레더코트로 덮어 마무리
- 힘줘서 닦지 않기 — 내부는 외부보다 훨씬 민감한 소재
- 한 번 작업한 곳을 다시 작업하지 않는 것이 시간 단축 최대 노하우
8-3. 운전석 타월 작업 순서
| 부위 | 세부 가이드 |
| --- | --- |
| 앞유리 | 맙타월 가장 깨끗한 상태에서 먼저 작업. 절반+한 뉴 습관 (나머지는 조수석에서). 맙타월 → 마른 극세사 타월로 마무리. 헤드라이트로 확인 필수 |
| 룸미러·선바이저 거울 | 앞유리 다음 순서. 맙타월 → 마른 타월 마무리 |
| 대시보드 | 맙타월로 먼지 제거. 유리에 타월이 닿지 않도록 주의 |
| 디스플레이·계기판 | 맙타월로 먼지·지문 제거 → 마른 타월 마무리. 코팅 케미컬 절대 금지 |
| 컵홀더 | 고무패킹·컵홀더 분리 → 클린앤코트 흔름 적셔 닦고 재조립 |
| 센터콘솔 | 팔꽔치 땀자국 다수 — 마무리 때 반드시 확인 |
| 버튼·다이얼 사이 | 틈새 놓치지 않도록 꽈꽈히 |
| 운전석 문 | 유리 맙타월 → 마른 타월. 창문·문틈 사이 닦기. 크롬 부분 마감. 문 손잡이 열어 내부 확인. 창문 버튼 손가락 들어가는 부분 |
8-4. 차량 하부 플라스틱 마감
- 닦아도 지워지지 않는 하단부 색 바랜 플라스틱 → 매트레더코트로 코팅
- 타이어 전용 마른 타월에 도포하여 색 복원
8-5. 페달 청소
- 클린앤코트로 닦기 또는 유리세정제 활용 (미끼러움 여부 확인)
---

### STEP 9. 매트 세철
- 매트를 벽에 대고 브러쉐로 위에서 아래로 털어낸다
- 먼지가 많으면 청소기로 선 청소 가능 (효과는 크지 않음)
- 색이 심하게 바랜 경우 레더왁스 소량 듚려 마감 가능
매트 종류별 처리:
- 순정 매트·고무 매트: 브러쉐 털기 후 필요 시 드레싱
- 코일 매트·벌집 매트: 털어내기 중심
매트는 발이 닿는 부분이라 드레싱 후 미끼러우면 클레임 발생 — 미끼러움 여부 반드시 확인. 스팀·다량 물 분사 금지 — 매트가 잘 안 마르면 퀴퀴한 냄새 클레임.
---

### STEP 10. 타이어 드레싱
타이어 광택 마감 — 전체 작업의 최후 단계다. 사진 촬영 직전, 모든 작업이 완료된 후 마지막에 진행한다.
- 1차 타월로 초벌해 놓은 타이어를 타이어 전용 마른 극세사 타월로 마무리
- 어떤 방법을 쓰더라도 마른 타월로 마감하지 않으면 잔사(물자국) 남음
- 타이어 드레싱 어플리케이터에 레더왁스 듹려 드레싱
- 고르게 분사 — 한 바퀴만 굴러도 안 된 부분이 바로 보임 → 꽈꽈히
- 앉아서 휠 청소 + 도장면 확인 + 말벌 동시 진행
- SUV 하단 스커트·플라스틱 가니쉐도 이때 드레싱제로 함께 색 복원
타이어 드레싱은 사진 촬영 직전, 모든 작업 완료 후 마지막에 진행한다. 빠뜨리는 경우 클레임 발생.
---

### STEP 11. 말벌 (마무리 점검)
도장면 최종 확인 및 잔사·얼룩 제거 단계다.
- 타이어 드레싱 하며 도장면을 함께 확인하고 말벌 진행
- 반드시 외부2차케미컬을 분사하여 말벌 진행 — 마른 타월로 도장면 문지르면 스크래치 발생
- 보닛 한 번 더 — 잔사가 잘 보이는 부위이므로
- 내 몸이 닿아 생친 땀자국·기름자국 발견하여 반드시 제거
유리에 왁스가 물으면 처리가 매우 곤란하다. 유리세정제를 도포하여 5분 이상 공들여야 제거된다. 왁스를 한 번이라도 듹릴 타월로 유리를 절대로 닦아내지 맘기. 왁스를 듹릴 부분은 반드시 버핑 완료 후 마무리한다.
