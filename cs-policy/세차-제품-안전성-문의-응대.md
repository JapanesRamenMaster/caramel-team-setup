## 요약
고객이 카라멜이 사용하는 세차 제품의 친환경 여부 또는 인체 안전성에 대해 문의하는 경우의 응대 기준. 
제품명 등 내부 정보는 외부에 노출하지 않으며, 안전성에 대한 기본적인 신뢰를 드리되 의학적 판단은 제공하지 않는다.

## 적용 조건
- 대상 고객: 전체
- 적용 상황: 사용 제품의 친환경 여부, 성분, 인체 안전성 등에 대한 문의 인입 시
- 적용 기간: 상시

## CS 처리 기준
| 문의 유형 | 처리 방향 |
| --- | --- |
| 친환경 인증 여부 문의 | 별도의 친환경 인증은 보유하고 있지 않음을 안내. 단, 시중에 정상 유통 중이며 국내 안전 기준을 충족한 제품만 사용함을 안내 |
| 인체 안전성 문의 | 시중에 정상 유통 중이며 국내 안전 기준을 충족한 제품을 사용하고 있어 일반적인 사용 환경에서 인체에 무해함을 안내. 단, 의학적 소견이나 성분별 상세 설명은 제공하지 않음. |
| 특정 성분 문의 | 사용 제품 및 성분 정보는 내부 정보로 외부에 공개하지 않음.  |
| 민감 체질 / 특수 상황 (영유아, 반려동물, 임산부 등) | 사람마다 민감도와 체질이 다를 수 있어 의학적 판단을 드리기 어려움을 안내. 특히 불안하신 경우 약품을 제외한 대체 세차 방식 안내 (아래 참고) |
대체 세차 방식 안내 (민감 고객 요청 시)
세척 약품 사용 없이 물, 물왁스, 알코올만으로 세차를 진행하는 방식을 선택하실 수 있다. 다만 약품을 사용하는 일반 세차에 비해 세척력 면에서 다소 아쉬운 부분이 있을 수 있음을 함께 안내한다.
> 처리 방법: CS 담당자가 어드민에서 해당 예약 건에 메모 기재 후 디테일러에게 전달

## 고객 안내 문구
기본 안전성 문의 시
> 카라멜에서 사용하는 세차 제품들은 시중에 정상적으로 유통되는 국내 안전 기준을 충족한 제품들로, 일반적인 사용 환경에서 인체에 무해한 수준입니다.
민감 체질 / 특수 상황 (신생아 등) 고객 문의 시
> 카라멜에서 사용하는 세차 제품들은 정부 인증 기준을 충족한 제품들로, 일반적인 사용 환경에서 인체에 무해합니다. 

## 주의 사항
- 사용 제품명, 브랜드, 성분 정보는 내부 정보로 고객 및 외부에 공개하지 않는다.
- "친환경 인증 제품을 사용한다"는 표현은 사용하지 않는다. (인증 없음)
- 의학적 판단이나 성분 분석은 제공하지 않으며, 지나친 확신을 주는 표현도 삼간다.
