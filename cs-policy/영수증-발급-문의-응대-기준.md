## 요약
고객이 영수증 발급을 요청하는 경우, 원칙적으로 결제 수단별 직접 발급 경로를 안내한다. 카라멜은 결제 대행사를 이용하고 있어 앱 내 별도 영수증 발급 기능을 제공하지 않는다. CS가 직접 발급해주는 것은 리소스 효율 및 재인입 방지를 위해 원칙적으로 하지 않으며, 예외적인 경우에만 고려한다.

## 적용 조건
- 대상 고객: 전체
- 적용 상황: 고객이 세차 이용 후 영수증 발급을 요청하는 경우
- 적용 기간: 상시

## CS 처리 기준
원칙: 고객에게 직접 발급 경로 안내
CS가 대신 발급하는 것은 원칙적으로 하지 않는다. 아래 결제 수단별 경로를 안내한다.
아래 결제 수단별 경로는 직접 검증하여 기록한 내용으로, 오류가 없음을 확인했습니다. (2025.03.11 기준)
| 결제 수단 | 발급 경로 |
| --- | --- |
| 토스페이 | 토스 앱 → 우측 상단 [결제] → [내역] → 카라멜 결제 건 선택 → 우측 상단 [거래명세서] |
| 신용카드 / 체크카드 | 카드 발급사 홈페이지 또는 앱 로그인 → [카드 이용내역] 또는 [카드 이용명세서] → 카라멜 결제 건 선택 → 카드매출전표 인쇄/다운로드. 카드사마다 경로 상이할 수 있으며, 자세한 안내는 해당 카드사로 문의 안내 |
| 카카오페이 | 카카오톡 앱 → 우측 하단 [···] 더보기 → 카카오페이 탭 우측 [결제] → 우측 상단 [톱니바퀴] → [결제 내역] → 카라멜 결제 건 선택 → [거래확인증] 또는 [현금영수증] 발급 |
| 토스페이·카카오페이로 현금(계좌이체 등) 결제 시 | 간편결제사에 등록된 정보 기준으로 현금영수증 자동 발급. 상세 문의는 해당 간편결제사로 안내 |
예외: CS 직접 발급 (포트원 관리자 콘솔 활용)
아래 상황에 해당하는 경우에 한해 CS 매니저 판단 하에 직접 발급을 고려할 수 있다.
- 고객이 발급 경로를 안내받았음에도 어려움을 지속 호소하는 경우
- 고객 온도감이 높아 직접 처리가 필요하다고 판단되는 경우
> 처리 방법: 포트원 관리자 콘솔 → 해당 결제 건 조회 → 영수증 확인 후 고객에게 발송

## 고객 안내 문구

> 영수증 발급 방법에 대해 안내드리겠습니다.
