## 요약
한 계정에 차량 여러 대를 등록하여 이용하는 것이 가능한지 묻는 고객 문의에 대한 응대 기준.

## 적용 조건
- 대상 고객: 전체 (1회 세차 / 구독 공통)
- 적용 상황: 고객이 다중 차량 등록 가능 여부를 문의할 때
- 적용 기간: 상시

## CS 처리 기준
| 상황 | 처리 기준 |
| --- | --- |
| 다중 차량 등록 가능 여부 문의 | 가능함. 고객 안내 문구 발송 |
| 구독 상품을 다른 차량에 쓸 수 있는지 문의 | 불가. 구독은 구매 시 지정한 차량에만 적용, 다른 차량으로 전용 불가 |
| 예약 시 차량을 잘못 선택한 경우 | 현장에서 추가 요금 발생 또는 작업 불가 가능성 안내 |
