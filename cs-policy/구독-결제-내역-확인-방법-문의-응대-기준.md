## 요약
구독 고객이 결제 내역 확인 방법을 문의할 때의 응대 기준. 앱 내 구독 관리 페이지에서 직접 확인 가능함을 안내한다.

## 적용 조건
- 대상 고객: 구독 고객
- 적용 상황: 구독 상품 결제 내역 확인 방법을 문의하는 경우
- 적용 기간: 상시

## CS 처리 기준
아래 고객 안내 문구를 발송하고 처리 종료한다.
- 별도 내부 보고 절차 없음
- 예외 사항 없음

## 고객 안내 문구
안녕하세요 고객님, 구독 상품 결제 내역 확인 방법을 안내드려요.
카라멜 앱 → 좌측 하단 [내 차고] 탭 → (차량이 여러 대인 경우) 상단에서 이용 중인 구독 상품의 차량 선택 → 우측 상단의 [(구독상품명) 구독 중>] 버튼 선택
구독 관리 페이지에서 지금까지의 구독 상품 결제 내역 확인이 가능합니다.

## 내부 처리 절차
없음. 고객 안내 문구 발송으로 처리 종료.
