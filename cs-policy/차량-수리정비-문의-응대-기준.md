### 핵심 규격
| 항목 | 내용 |
| --- | --- |
| 제공 가능 정비 항목 | 타이어 교체, 오일 교환, 유리 교체·복원, 찍힘·기스 수리(도색/판금), 일반 차량 점검·정비 — 모두 자체 정비 시설에서 직접 진행 |
| 선제적 정비 제안 | 세차 진행 중 계기판 이상·타이어 상태·외판 이상 발견 시 고객에게 먼저 안내 |
| 점검 방법 | 세차 전일 디테일러 연락 시 정비 필요 부위 말씀 → 방문 시 현장에서 사진·영상 기록 후 트라이브 차량팀 전달 |
| 견적 | 실제 차량 상태를 현장에서 직접 확인해야 정확한 견적 안내 가능 — 디테일러 방문 점검이 전제. 공식 서비스 대비 투명하고 합리적인 가격. 견적 후 진행 여부는 고객이 자유롭게 결정 |
| 차량 이동 | 고객 직접 방문 불필요 — 전문 탁송업체가 원하는 시간·장소에서 차량 인수 → 정비 후 고객 지정 장소로 반납 |
| 작업 시간 | 당일 작업 가능 시 오전 인수 → 오후 반납. 작업마다 소요 시간 상이 — 견적 시 사전 안내 후 고객과 일정 협의 |

### 고객 안내 문구
```javascript
차량 수리나 정비가 필요하신 경우, 따로 시간을 내어 정비소를 직접 방문하지 않으셔도 됩니다.

카라멜은 세차와 함께 차량 상태를 점검하고 필요한 정비를 원스톱으로 연결해 드리고 있습니다. 타이어 교체, 오일 교환, 유리 교체·복원, 찍힘·기스 수리(도색/판금), 일반 점검 등 다양한 정비를 자체적으로 진행하고 있어요.

담당 디테일러가 방문 전날 미리 연락을 드리는데, 그때 어떤 부분의 정비가 필요하신지 말씀해 주시면 방문 시 해당 부위를 직접 확인하고 사진·영상으로 기록하여 저희 트라이브 차량팀에 전달해 드립니다. 또한 세차를 진행하는 과정에서 계기판 이상이나 타이어·외판 상태 등 신경 쓰이는 부분이 발견되면 저희가 먼저 말씀드리기도 합니다.

정확한 견적은 디테일러가 방문하여 실제 차량 상태를 직접 확인한 후에 안내드릴 수 있습니다. 공식 서비스 견적과 비교한 투명하고 합리적인 가격으로 안내드리며, 견적을 받아보신 후 진행 여부는 고객님이 자유롭게 결정하실 수 있습니다.

정비를 진행하시게 되면, 전문 탁송업체를 통해 원하시는 시간과 장소에서 차량을 인수하여 저희 정비 시설에서 작업 후 고객님께서 원하시는 곳으로 다시 돌려드립니다. 당일 작업이 가능한 경우 오전 인수 후 오후 반납을 목표로 하고 있으며, 작업 내용에 따라 소요 시간이 달라질 수 있어 견적 시 사전에 안내드리겠습니다.
```
