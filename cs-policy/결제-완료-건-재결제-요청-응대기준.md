## 요약
고객 사유로 결제 완료 건의 재결제(결제수단 변경)을 요청하는 경우의 응대 기준.
이용 개시 전 미사용 상품은 고객이 직접 환불 후 재구매를 안내하고, 이용 개시 후에는 변경 불가를 안내한다. 불가 안내 후에도 미수긍 시 CS 매니저 판단에 따라 예외적으로 수기 재결제 처리가 가능하다.

## 적용 조건
- 대상 고객: 전체 (1회·구독 공통)
- 적용 상황: 고객이 결제 완료 건의 결제수단을 다른 수단으로 변경 요청하는 경우
- 적용 기간: 상시

## CS 처리 기준
| 상황 | 처리 방법 |
| --- | --- |
| 미사용 1회권 + 무료 취소 가능 기간 내 (예약 전일 19:59:59 이전) | 고객이 직접 앱에서 예약 취소 → 환불 후 재구매 안내 (고객 안내 문구 1) |
| 미사용 구독 상품 | 고객이 직접 앱에서 구독 해지 → 환불 후 재구매 안내 (고객 안내 문구 1) |
| 이용 개시 후 결제 완료 건 | 시스템상 결제 취소 및 재결제 불가 안내 (고객 안내 문구 2) |
| 불가 안내 후 미수긍 — 법인카드 오결제로 고객 불이익 우려 | CS 매니저 판단 하에 예외적 수기 재결제 처리 + 향후 주의 안내 (고객 안내 문구 3-A) + 내부 처리 절차 참조 |
| 불가 안내 후 미수긍 — 개인 사유 지속 요구로 응대 리소스가 더 큰 경우 | CS 매니저 판단 하에 수기 재결제 처리 + 1회성 처리임을 안내 (고객 안내 문구 3-B) + 내부 처리 절차 참조 |

## 고객 안내 문구 1 (미사용 상품 — 환불 후 재구매 안내)
> 고객님, 문의 주셔서 감사합니다.

## 고객 안내 문구 2 (이용 개시 후 — 변경 불가 안내)
> 고객님, 문의 주셔서 감사합니다.

## 고객 안내 문구 3-A (법인카드 오결제 — 예외 처리 시)
> 고객님, 문의 주셔서 감사합니다.

## 고객 안내 문구 3-B (개인 사유 지속 요구 — 예외 처리 시)
> 고객님, 문의 주셔서 감사합니다.

## 내부 처리 절차 (수기 재결제)
[공통] 1회권 / 다회권 / 해지된 구독 상품 + 구독 중이나 이번만 다른 결제수단으로 결제하는 경우
1. 카라멜 어드민 → 고객 목록 → 전화번호로 해당 고객 조회
1. 좌측 상단 [결제 생성] 버튼 클릭
1. 결제명: 상품명 + 원 결제 일자 + 재결제요청 (예: 외부세차 1회권 2026-03-12 재결제요청)
1. 고객에게 결제 안내 후 결제 완료 확인 요청
1. 고객이 결제 완료 알림 시 → 포트원 관리자콘솔에서 결제 성공 여부 확인
1. 확인 후 기존 결제 건을 포트원 관리자콘솔에서 결제 취소
[구독 상품 — 앞으로도 해당 결제수단으로 계속 결제해야 하는 경우]
1. 고객에게 구독 해지 먼저 안내
  - 경로: 카라멜 앱 → 좌측 하단 [내 차고] 탭 → 상단에서 해당 차량 선택 → 우측 상단 [(구독상품명) 구독 중 >] 버튼 → 우측 상단 [구독 취소] 버튼
  - ⚠️ 분기점 주의: 잔여 세차권이 있는 경우 반드시 [세차권 다음에 사용하기] 선택
  - [세차권 환불받기] 선택 시 부분환불 처리되어 재결제 금액 불일치 발생
1. 구독 해지 완료 후 위 공통 절차와 동일하게 수기 청구 처리
1. 처리 완료 후 고객 안내: 구독 재개를 원하는 시점에 변경하시려는 결제수단으로 새로 구독 상품을 구매하여 구독 시작
