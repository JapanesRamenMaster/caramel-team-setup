## 요약
비동절기임에도 예약 화면에서 "동절기에는 실외 세차가 제한됩니다" 오류가 표시되며 예약이 불가한 경우의 응대 기준. 인지된 버그이며, 임시 해결 방법을 안내한다.

## 적용 조건
- 대상 고객: 전체
- 적용 상황: 예약 시도 중 동절기 제한 오류 메시지로 예약 불가 문의 시
- 적용 기간: 버그 수정 완료 시까지

## CS 처리 기준
- 인지된 버그임을 내부 확인. 수정 진행 중.
- 임시 해결 방법: 예약 화면 주소 란에서 수정 버튼(연필 아이콘) 클릭 → 같은 주소지 다시 추가 → 새로 추가한 주소지로 예약 시도

## 고객 안내 문구
안녕하세요 고객님, 우선 불편을 드려 죄송합니다.
해당 오류는 인지하고 있으며 빠르게 수정할 수 있도록 하겠습니다.
임시 해결 방안을 안내드려요. 예약 화면의 주소 란에서 수정 버튼(연필 아이콘)을 누르신 뒤 같은 주소지를 다시 추가하신 후, 새로 추가하신 주소지로 예약 시도하시면 같은 문제가 발생하지 않습니다.
불편을 드려 죄송합니다.
