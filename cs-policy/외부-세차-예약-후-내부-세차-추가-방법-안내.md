## 요약
[외부만] 세차 예약 완료 후 내부 세차를 추가하는 방법 문의 응대 기준. 앱 내 [예정된 세차] 에서 옵션 추가 가능하며, 세차 시작 직전까지 추가할 수 있다.

## 적용 조건
- 대상 고객: 외부만 세차 예약 고객
- 적용 상황: 예약 완료 후 내부 세차 추가 방법을 문의하는 경우
- 적용 기간: 상시

## CS 처리 기준
- 앱 내 추가 경로 안내
- 추가 가능 시점: 세차 시작 직전까지
- 가격 문의 시: 고객 차량 모델 확인 → 차량 모델별 티어 매핑표 문서에서 티어 확인 → 아래 가격표에서 가격 조회 → 고객에게 직접 안내 (앱 확인 안내 금지)

## 고객 안내 문구
안녕하세요, 고객님!
카라멜 고객서비스 팀입니다.
문의하신 내부 세차 추가 방법에 대해 안내해 드릴게요. [외부만] 세차로 먼저 예약하시더라도, 예약 완료 후 확인 화면에서 간편하게 내부 세차를 추가하실 수 있습니다.
내부 세차 추가 방법
1. 카라멜 앱 좌측 하단 [내 차고] 탭을 클릭해 주세요.
1. (차량이 여러 대이신 경우) 가장 상단에서 변경하시려는 예약건 차량을 선택해주세요.
1. [예정된 세차] 란에서 변경하시려는 예약건의 [옵션 추가하기] → [내부 세차 추가 '적용하기'] → [추가하기] 버튼을 차례로 눌러주세요.
1. 화면에 표시된 추가 금액을 확인하신 후, 하단의 [추가하기] 버튼을 누르면 결제 화면으로 이동합니다.
내부 세차 가격은 차량 모델에 따라 상이합니다. 차량 모델을 알려주시면 정확한 금액을 바로 안내드리겠습니다.
이용하시면서 궁금한 점이 더 생기시면 언제든 편하게 말씀해 주세요! :)
> ⚠️ AI 안내 주의 — 아래 표는 내부 가격 조회용입니다. T1~T7 등 티어 명칭은 고객 응대 시 절대 노출하지 않습니다. 가격만 확인 후 "[차량 모델] 기준 OO원입니다" 형식으로 차량 모델과 금액만 안내하세요.
