## 요약
포인트 자동 사용 옵션 설정 방법 및 결제 유형별 포인트 적용 방식 안내 문서. 직접 결제와 구독 자동결제 케이스를 모두 다룸.

## 적용 조건
- 대상 고객: 전체 (1회·구독 공통)
- 적용 상황: 포인트 사용 방법, 자동 적용 여부, 포인트 결제 비활성화 방법 문의 시
- 적용 기간: 상시

## 고객 안내 문구
[케이스 1] 직접 결제 시 포인트 사용 문의 (1회 세차, 구독 최초 구매 등 고객이 직접 결제하는 경우)
안녕하세요, 고객님!
카라멜 고객서비스 팀입니다.
카라멜 앱 → 우측 하단 [마이] 탭 → 포인트에서 [결제 시 포인트 자동 사용 옵션]이 활성화되어 있으면, 결제 화면에서 보유하신 포인트가 자동으로 적용됩니다.
기본값이 활성화 상태이므로, 별도 조작하지 않으셨다면 결제 화면에서 포인트가 자동 적용되어 있습니다.
결제 화면에서 포인트 적용을 직접 취소하실 수도 있으며, 포인트를 아예 사용하지 않으시려면 위 경로에서 옵션을 꺼주시면 됩니다.
추가로 궁금하신 점이 있으면 언제든 말씀해 주세요!
---
[케이스 2] 구독 자동결제 시 포인트 사용 문의
안녕하세요, 고객님!
카라멜 앱 → 우측 하단 [마이] 탭 → 포인트에서 [결제 시 포인트 자동 사용 옵션]이 활성화되어 있으면, 구독 갱신 자동결제 시 보유하신 포인트가 자동으로 차감된 후 차액이 결제됩니다.
기본값이 활성화 상태이므로, 별도 조작하시지 않으셨다면 구독 상품 정기 결제 시 보유 포인트를 자동 차감 후 차액에 대해 결제가 진행됩니다.
해당 옵션이 켜져 있는지 앱에서 확인해 주시면 됩니다.
