## 적용 조건 (when_to_use)
고객이 앱 예약 화면에서 볼 수 없는 현장 전용 옵션(송진 제거·스티커 제거·석회수 제거·탈취캔)의 존재나 추가 가능 여부를 문의하는 경우.

## 비적용 조건 (not_when_to_use)
- ⛔ 앱에서 이미 노출되는 일반 옵션 추가 가능 여부 문의 → '현장 옵션 추가 가능 여부 문의 응대 (공통 기준)' entry 사용
- ⛔ 세차 종료 이후 현장 전용 옵션 추가를 요청하는 경우 (추가 불가)

## 처리 방법
실제 작업 가능 여부를 현장에서 직접 확인해야 하는 특성상 앱에 노출하지 않음. 디테일러가 예약 전일 연락 시 미리 요청하거나, 현장에서 디테일러가 필요하다고 판단 시 추천.

현장 전용 옵션 목록:
- 송진 제거: 개당 10,000원 / 전문 케미컬 우선 적용 → 제거 어려운 경우 연마제+연마기기 부분 사용
- 스티커 제거: 개당 10,000원 / 스팀기 가열 또는 전용 케미컬 사용 / 주의: 오염 종류에 따라 작업 불가한 경우 있음. 정확한 가능 여부는 디테일러가 현장에서 최종 판단
- 석회수 제거: 판당 50,000원 / 전문 케미컬+광택기로 도장면 바깥을 연마하여 제거. 판 = 차량 외관을 구성하는 각 패널(부위) 1개 (예: 본넷, 도어 한 짝, 펜더, 트렁크, 루프 등) / 주의: 오염 발생 후 시간이 경과된 경우 도장면 내부까지 이염되어 완벽 제거 불가. 해당 부분은 재도색이 필요한 케이스로 타 업체도 동일
- 탈취캔: 30,000원 / 전문 탈취 제품 사용. 분사 성분이 차량 내부와 공조 시스템 전체를 순환하며 냄새 입자 분해+유해균 제거 / 주의: 시공 직후 일정 기간 제품 냄새 강할 수 있음 — 고객에게 사전 안내 필요

현장 결제 방법:
- 온라인 결제 링크: 디테일러가 고객에게 링크 전송
- 법인 계좌 입금: 현금영수증 발행 가능
- 현장 카드 단말기: 디테일러 소지 단말기로 결제

## 고객 안내 문구
앱 예약 화면에는 보이지 않지만 현장에서 추가 가능한 옵션도 있습니다. 차량 상태를 직접 확인해야 작업 가능 여부를 판단할 수 있는 옵션들로, 디테일러가 예약 전날 연락드릴 때 미리 말씀해 주시거나 현장에서 요청해 주시면 됩니다.

## 주의사항
탈취캔 시공 시 고객에게 시공 직후 일정 기간 제품 냄새가 강할 수 있음을 사전 안내 필수.
