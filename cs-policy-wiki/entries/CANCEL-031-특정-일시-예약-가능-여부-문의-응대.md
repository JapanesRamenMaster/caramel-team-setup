## 적용 조건 (when_to_use)
고객이 특정 날짜·시간의 예약 가능 여부를 문의하거나(예: '~일 ~시 예약 가능한가요?'), 왜 특정 일시에 예약이 안 되는지 묻는 경우.

## 비적용 조건 (not_when_to_use)
- ⛔ 이미 예약된 건의 일정 변경 요청 케이스에서는 이 entry 사용 금지 (→ 별도 예약 변경 entry 참조, 문서 코드 31fd)
- ⛔ 예약 취소 처리 요청(취소 수수료·환불 등)에는 이 entry 사용 금지
- ⛔ 앱 오류·결제 오류로 예약이 안 되는 경우에는 이 entry 사용 금지

## 처리 방법
- 예약 불가 원인은 앱에서 실시간으로 확인 가능하며, CS에서 특정 일시의 가능 여부를 사전 보장하지 않는다.
- 예약 불가 주요 원인:
  1. 해당 시간대가 2시간 단위 슬롯에 해당하지 않는 경우 (예: 9시, 13시, 11시 30분) — 슬롯 자체가 없어 아예 예약 불가
  2. 해당 일시에 이미 다른 고객 예약이 있는 경우
  3. 디테일러 이동 경로상 해당 위치가 포함되지 않는 경우
  4. 디테일러가 해당 일시에 비가용 상태인 경우
- 고객이 지속적으로 요청하는 경우, 앱 알림 기능을 안내하거나 다른 날짜 이용을 권유한다.

## 고객 안내 문구
[예약 가능 시간대 문의 시]
[2시간 단위 슬롯에 해당하지 않는 시간대 문의 시 (예: 오전 9시, 오후 1시 등)]

## 주의사항
CS에서 특정 일시의 예약 가능 여부를 사전 보장하거나 확약하지 않는다. 앱 내 실시간 일정 확인을 안내하는 것이 원칙이다.
