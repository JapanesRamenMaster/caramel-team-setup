## 적용 조건 (when_to_use)
매 세차 건 출발 후 현장으로 이동 중, 고객에게 사전 연락하는 경우.

## 비적용 조건 (not_when_to_use)
- ⛔ 지각이 예상되는 경우 → DAILY-019 사용 (별도 연락 절차)

## 처리 방법
출발하면서 고객에게 전화하여 확인:
1. 네비게이션 기준 도착 시간 (여유있게 안내)
2. 입출차 방법 논의 ("몇동 몇호 방문입니다" — 세차하러 왔다고 경비실에 알릴 필요 없음)
3. 주차 위치 확인
   - 고객이 입력한 경우 → "적어주신 주차 위치 맞을까요?"
   - 고객이 입력하지 않은 경우 → "주차 위치가 어디인가요?"
4. 키 수령 방법 문의
5. 세차 시 더욱 신경 써야 할 부분 문의 (비대면 키 수령 시)

주의: 디테일러 웹에서 주차 위치 확인 후 전화할 것. 고객이 이미 입력했는데 다시 물어보면 신뢰 저하.
