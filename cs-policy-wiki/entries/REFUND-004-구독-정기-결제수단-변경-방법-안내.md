## 적용 조건 (when_to_use)
구독 이용 고객이 정기 결제수단을 변경하고 싶다고 문의하는 경우. 앱 내 직접 변경 기능이 없어 해지 후 재구매 방식을 안내해야 할 때.

## 비적용 조건 (not_when_to_use)
- ⛔ 고객이 구독 자체를 완전히 해지(탈퇴)하고 싶은 경우 — 결제수단 변경 목적이 아닌 순수 해지 문의에는 이 entry 사용 금지
- ⛔ 정기결제일에 결제가 실패하여 앱에 결제수단 변경 버튼이 이미 노출된 경우 — 별도 결제 실패 대응 프로세스 적용
- ⛔ 구독이 아닌 단건(일회성) 결제수단 변경 문의에는 이 entry 사용 금지

## 처리 방법
고객 안내 문구 참고하여 해지 후 재구매 방식 안내.

**[기존 구독 해지 방법]**
카라멜 앱 → 우측 하단 [내 차고] 탭 → (차량 여러 대면) 구독 차량 선택 → 우측 상단 [XX 구독중] → [구독 취소]

해지 시 세차권 옵션:
- **세차권 환불받기**: 미사용 세차권 전액 환불 후 즉시 재구매 가능 (사용분은 정상가 기준 차감)
- **세차권 다음에 사용하기**: 이미 세차권을 일부 사용했다면 이 옵션이 유리

**[구독 상품 재구매]**
카라멜 앱 → 우측 하단 [내 차고] 탭 → 구독 차량 선택 → 우측 상단 [구독 시작하기] → 원하는 상품 선택 후 새 결제수단으로 결제

## 고객 안내 문구
현재 카라멜 서비스 내에서 구독 상품의 정기 결제 수단을 직접 변경하는 기능이 제공되지 않습니다. 기존 구독을 해지하신 후 변경 원하시는 새로운 결제 수단으로 재구매해 주셔야 합니다.

또는, 정기결제일에 기존 결제수단으로 결제 실패되는 경우에 한하여 앱 내 메인 화면 하단에 결제 수단 변경 버튼이 노출됩니다.

**[기존 구독 해지 방법]**
카라멜 앱 → 우측 하단 [내 차고] 탭 → (차량 여러 대면) 구독 차량 선택 → 우측 상단 [XX 구독중] → [구독 취소]

해지 시 세차권 옵션:
- **세차권 환불받기**: 미사용 세차권 전액 환불 후 즉시 재구매 가능 (사용분은 정상가 기준 차감)
- **세차권 다음에 사용하기**: 이미 세차권을 일부 사용했다면 이 옵션이 유리

**[구독 상품 재구매]**
카라멜 앱 → 우측 하단 [내 차고] 탭 → 구독 차량 선택 → 우측 상단 [구독 시작하기] → 원하는 상품 선택 후 새 결제수단으로 결제

## 주의사항
앱 내 직접 결제수단 변경 기능이 출시되면 이 entry는 즉시 업데이트 필요. 현재는 해지 후 재구매 방식만 안내.
