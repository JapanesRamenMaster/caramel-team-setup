## 적용 조건 (when_to_use)
고객이 1회 세차, 구독 최초 구매 등 직접 결제하는 상황에서 포인트 사용 방법, 자동 적용 여부, 포인트 비활성화 방법을 문의하는 경우.

## 비적용 조건 (not_when_to_use)
- ⛔ 구독 갱신 자동결제 시 포인트 적용 방식 문의 — 해당 케이스는 케이스 2(구독 자동결제 포인트 안내) entry 사용
- ⛔ 포인트 적립 방식이나 포인트 잔액 확인 문의 (별도 정책 entry 사용)

## 처리 방법
고객 안내 문구(케이스 1) 전달:
카라멜 앱 → 우측 하단 [마이] 탭 → 포인트에서 [결제 시 포인트 자동 사용 옵션] 활성화 여부 확인 안내.
기본값이 활성화 상태임을 고지.
결제 화면에서 포인트 적용 직접 취소 가능함을 안내.
포인트를 아예 사용하지 않으려면 위 경로에서 옵션을 끄도록 안내.

## 고객 안내 문구
안녕하세요, 고객님!
카라멜 고객서비스 팀입니다.
카라멜 앱 → 우측 하단 [마이] 탭 → 포인트에서 [결제 시 포인트 자동 사용 옵션]이 활성화되어 있으면, 결제 화면에서 보유하신 포인트가 자동으로 적용됩니다.
기본값이 활성화 상태이므로, 별도 조작하지 않으셨다면 결제 화면에서 포인트가 자동 적용되어 있습니다.
결제 화면에서 포인트 적용을 직접 취소하실 수도 있으며, 포인트를 아예 사용하지 않으시려면 위 경로에서 옵션을 꺼주시면 됩니다.
추가로 궁금하신 점이 있으면 언제든 말씀해 주세요!
