## 적용 조건 (when_to_use)
고객이 신규 예약을 진행하는 과정에서 방문 주소를 변경하거나 새로운 주소를 추가하고 싶다고 요청하는 경우.

## 비적용 조건 (not_when_to_use)
- ⛔ 이미 완료된 기존 예약 건의 주소를 변경하려는 경우 — 앱 경로가 다름 (→ 케이스 1 entry 사용)

## 처리 방법
카라멜 앱 실행 → 좌측 하단 [내 차고] 탭 → 일정 선택 캘린더 위 주소란의 우측 [수정] 버튼 (연필 아이콘) 클릭 후 주소 선택
> 기존 등록된 주소록에 없는 신규 주소는 해당 화면 하단의 [새로운 주소 추가하기]로 추가 가능

## 고객 안내 문구
안녕하세요, 고객님. 카라멜입니다.
신규 예약 시 방문 주소 변경은 아래와 같이 진행해 주세요.
카라멜 앱 실행 → 좌측 하단 [내 차고] 탭 → 일정 선택 캘린더 위 주소란의 우측 [수정] 버튼 (연필 아이콘) 클릭 후 주소 선택
기존 등록하신 주소록에 없는 새로운 주소는 해당 화면 하단의 [새로운 주소 추가하기]를 통해 추가하실 수 있습니다.
추가 문의 사항이 있으시면 언제든지 말씀해 주세요.
