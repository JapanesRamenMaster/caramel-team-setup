## 적용 조건 (when_to_use)
고객이 환불 입금 시점을 문의하였으나, 확인 결과 앱에서 환불하기 버튼을 아직 누르지 않은 경우.

## 비적용 조건 (not_when_to_use)
- ⛔ 고객이 이미 환불 버튼을 누른 경우 — 별도 entry '환불 소요 시간 문의 — 환불 버튼 이미 누른 경우' 사용
- ⛔ 환불 방법을 상세히 안내해야 하는 경우 (→ 「환불 방법 문의 시 응대 기준」 참조)
- ⛔ 환불 버튼 클릭 여부를 확인하지 않고 소요 시간을 먼저 안내하는 경우

## 처리 방법
1. 고객이 앱에서 환불하기 버튼을 실제로 눌렀는지 먼저 확인한다.
2. 아직 누르지 않은 경우 → 앱에서 먼저 환불 처리를 진행하도록 안내한다.
3. 상품별 환불 방법은 「환불 방법 문의 시 응대 기준」 참조.

## 고객 안내 문구
환불을 받으시려면 앱에서 먼저 환불 처리를 진행해 주셔야 합니다. 환불 방법 안내가 필요하시면 말씀해 주세요!
