## 적용 조건 (when_to_use)
고객이 구독 갱신 자동결제 시 포인트가 자동으로 차감되는지 여부, 적용 방식, 옵션 설정 방법을 문의하는 경우.

## 비적용 조건 (not_when_to_use)
- ⛔ 1회 세차 또는 구독 최초 구매 등 고객이 직접 결제하는 케이스 — 해당 케이스는 케이스 1(직접 결제 포인트 안내) entry 사용
- ⛔ 포인트 적립 방식이나 포인트 잔액 확인 문의 (별도 정책 entry 사용)

## 처리 방법
고객 안내 문구(케이스 2) 전달:
카라멜 앱 → 우측 하단 [마이] 탭 → 포인트에서 [결제 시 포인트 자동 사용 옵션] 활성화 여부 확인 안내.
기본값이 활성화 상태임을 고지.
구독 갱신 자동결제 시 보유 포인트 자동 차감 후 차액 결제됨을 안내.
앱에서 해당 옵션 활성화 여부 직접 확인하도록 안내.

## 고객 안내 문구
안녕하세요, 고객님!
카라멜 앱 → 우측 하단 [마이] 탭 → 포인트에서 [결제 시 포인트 자동 사용 옵션]이 활성화되어 있으면, 구독 갱신 자동결제 시 보유하신 포인트가 자동으로 차감된 후 차액이 결제됩니다.
기본값이 활성화 상태이므로, 별도 조작하시지 않으셨다면 구독 상품 정기 결제 시 보유 포인트를 자동 차감 후 차액에 대해 결제가 진행됩니다.
해당 옵션이 켜져 있는지 앱에서 확인해 주시면 됩니다.
