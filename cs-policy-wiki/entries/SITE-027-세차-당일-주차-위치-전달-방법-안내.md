## 적용 조건 (when_to_use)
고객이 세차 당일 주차 위치를 디테일러에게 어떻게 전달하는지 문의할 때, 또는 채널톡으로 주차 위치를 남긴 경우.

## 비적용 조건 (not_when_to_use)
- ⛔ 주차 위치가 아닌 예약 변경·취소 문의인 경우 (별도 예약/변경/취소 entry 사용)
- ⛔ 디테일러가 이미 현장에 도착했으나 주차 위치를 찾지 못하는 현장 상황 (별도 현장대응 entry 사용)

## 처리 방법
아래 세 가지 방법 중 편한 방법으로 주차 위치를 전달하도록 안내한다.
방법 1. 앱 내 직접 등록 (권장): 주차 완료 후 앱 내 좌측 하단 [내 차고] 탭 → [예정된 세차] 탭의 해당 예약건 하단의 [주차 위치 등록] 또는 [주차 위치 변경] 클릭
방법 2. 디테일러 방문 전날 연락 시 전달: 세차 전날 디테일러가 먼저 연락을 드리고 있으니, 그때 말씀해 주셔도 됨
방법 3. 디테일러에게 직접 연락: 세차일 전일 오후 8시부터 앱 내 디테일러 연락처가 표시됨. 확인 방법: 카라멜 앱 → 좌측 하단 [내 차고] 탭 → 해당 예약 카드 최하단
