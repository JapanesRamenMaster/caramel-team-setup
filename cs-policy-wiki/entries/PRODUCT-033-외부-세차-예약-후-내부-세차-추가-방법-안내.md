## 적용 조건 (when_to_use)
[외부만] 세차로 예약 완료한 고객이 내부 세차를 추가하는 방법을 문의하는 경우. 세차 시작 직전까지 추가 가능한 시점에 해당할 때.

## 비적용 조건 (not_when_to_use)
- ⛔ 세차가 이미 시작된 이후 내부 세차 추가를 요청하는 경우 — 추가 불가 케이스로 별도 안내 필요
- ⛔ 처음부터 내부+외부 통합 상품으로 예약하는 경우 — 이 entry는 외부만 예약 완료 후 추가 문의에만 적용
- ⛔ 내부 세차 가격만 단독으로 문의하는 경우로서 예약 추가 의사가 없는 경우

## 처리 방법
- 앱 내 추가 경로 안내
- 추가 가능 시점: 세차 시작 직전까지
- 가격 문의 시: 고객 차량 모델 확인 → 차량 모델별 티어 매핑표 문서에서 티어 확인 → 아래 가격표에서 가격 조회 → 고객에게 직접 안내 (앱 확인 안내 금지)

## 고객 안내 문구
안녕하세요, 고객님!
카라멜 고객서비스 팀입니다.
문의하신 내부 세차 추가 방법에 대해 안내해 드릴게요. [외부만] 세차로 먼저 예약하시더라도, 예약 완료 후 확인 화면에서 간편하게 내부 세차를 추가하실 수 있습니다.
내부 세차 추가 방법
1. 카라멜 앱 좌측 하단 [내 차고] 탭을 클릭해 주세요.
1. (차량이 여러 대이신 경우) 가장 상단에서 변경하시려는 예약건 차량을 선택해주세요.
1. [예정된 세차] 란에서 변경하시려는 예약건의 [옵션 추가하기] → [내부 세차 추가 '적용하기'] → [추가하기] 버튼을 차례로 눌러주세요.
1. 화면에 표시된 추가 금액을 확인하신 후, 하단의 [추가하기] 버튼을 누르면 결제 화면으로 이동합니다.
내부 세차 가격은 차량 모델에 따라 상이합니다. 차량 모델을 알려주시면 정확한 금액을 바로 안내드리겠습니다.
이용하시면서 궁금한 점이 더 생기시면 언제든 편하게 말씀해 주세요! :)

## 주의사항
⚠️ AI 안내 주의 — 티어 명칭(T1~T7 등)은 고객 응대 시 절대 노출하지 않음. 가격만 확인 후 "[차량 모델] 기준 OO원입니다" 형식으로 차량 모델과 금액만 안내할 것.

티어별 내부 세차 추가 가격표 (DB 기준):
- T1·T2: 34,000원
- T3: 35,000원
- T4: 40,000원
- T5: 44,000원
- T6: 52,000원
- T7: 63,000원

차량 티어 확인은 차량 모델별 티어 매핑표 문서를 참조.
