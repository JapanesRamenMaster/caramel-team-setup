## 적용 조건 (when_to_use)
고객이 차량 추가 등록 방법을 문의하거나, 여러 대 차량 이용 시 주의사항을 문의하는 경우. 1회·구독 고객 모두 적용.

## 비적용 조건 (not_when_to_use)
- ⛔ 이미 등록된 차량 정보를 수정하거나 삭제하는 방법을 문의하는 경우 (별도 entry 사용)
- ⛔ 잘못된 차량으로 예약이 완료된 후 추가 요금 분쟁이 발생한 경우 (현장대응 entry 사용)
- ⛔ 구독 상품을 잘못된 차량으로 결제한 후 환불·변경을 요청하는 경우 (결제/환불 entry 사용)

## 처리 방법
아래 고객 안내 문구를 그대로 전달한다.

## 고객 안내 문구
안녕하세요, 카라멜 서비스를 이용해 주셔서 감사합니다.
저희 서비스는 차량 여러 대를 동시에 등록하여 편리하게 이용하실 수 있습니다.
차량 추가 등록 방법과 이용 시 주의사항을 안내해 드릴게요.

차량 추가 등록 방법
카라멜 앱 실행 → 좌측 하단 [내 차고] 탭 → 상단의 차량 선택 란 우측 [+] 버튼을 통해 차량 추가가 가능합니다.

차량 여러 대 이용 시 주의사항
1. 세차 예약 시 차량 확인
차량 모델별로 가격과 작업 시간이 다르게 책정됩니다.
세차 예약 시에는, 예약 화면 상단에 표시된 차량 정보가 실제 세차할 차량과 일치하는지 꼭 확인해 주세요.
잘못된 차량으로 예약하실 경우, 현장에서 추가 요금이 발생하거나 작업이 어려울 수 있습니다.

2. 구독 상품 구매 시 차량 확인
구독 상품 역시 모델별로 가격이 다르며, 특정 차량으로 구매한 구독 상품의 세차권은 해당 차량에만 적용됩니다.
구매 화면 상단의 차량 정보를 반드시 확인하신 후 결제해 주시기 바랍니다.

추가로 궁금하신 점이 있다면 언제든 말씀해 주세요.
감사합니다!
