## 적용 조건 (when_to_use)
구독 고객(월 2회 외부 또는 월 4회 외부)이 자동 예약 기능을 비활성화(끄기)하고 싶다고 요청하는 경우.

## 비적용 조건 (not_when_to_use)
- ⛔ 자동 예약이 생성된 이유만 묻는 경우 — 별도 entry(자동 예약 생성 이유 문의) 사용
- ⛔ 월 1회(내부+외부) 구독 고객의 문의 — 해당 상품은 자동 예약 없음, 이 entry 적용 불가
- ⛔ 일반(비구독) 고객의 예약 취소 요청

## 처리 방법
- 앱 내 자동 예약 비활성화 기능은 제공되지 않음을 안내
- 원하지 않는 예약은 예약 전날 오후 8시 이전에 직접 취소하도록 안내
- 전날 오후 8시 이전 취소 시 전액 환불 또는 세차권 복구됨을 안내
- 취소 방법 안내: 카라멜 앱 → 좌측 하단 [내 차고] 탭 → 해당 예약 하단 [예약 변경/취소]

## 고객 안내 문구
고객님, 문의 주셔서 감사합니다.
현재 앱 내에서 자동 예약을 비활성화하는 기능은 제공되지 않습니다. 양해 부탁드립니다.
자동 예약은 저희 서비스 일정이 빠르게 선점되는 경우가 많아, 고객님이 원하시는 날짜에 세차를 받으실 수 있도록 미리 자리를 확보해 드리는 목적으로 운영되고 있습니다. 자동 예약이 잡혀있더라도 예약 전날 오후 8시 이전에는 언제든지 취소하실 수 있어 고객님께 별도의 불이익은 없습니다.
원하지 않으시는 예약은 예약 전날 오후 8시 이전에 취소해 주시면 되고, 취소 시 전액 환불 혹은 세차권이 복구되니 걱정 없이 이용해 주세요.
취소 방법: 카라멜 앱 → 좌측 하단 [내 차고] 탭 → 해당 예약 하단 [예약 변경/취소]
