## 적용 조건 (when_to_use)
구독 고객이 구독 해지를 요청하는 경우. 해지 사유가 차량 변경이 아닌 일반 해지일 때.

## 비적용 조건 (not_when_to_use)
- ⛔ 해지 사유가 차량 변경인 경우 — 이 entry 사용 금지 (→ 「구독 이용 중 차량 변경 문의 응대 기준」 참조)
- ⛔ 구독 일시 정지 요청인 경우 — 별도 entry(구독 일시 정지 안내) 사용
- ⛔ 정지 기간 중 조기 재개 요청인 경우 — 별도 entry(조기 재개 처리) 사용

## 처리 방법
1. 해지 사유가 차량 변경인지 먼저 확인. 차량 변경이면 「구독 이용 중 차량 변경 문의 응대 기준」으로 분기.
2. 차량 변경이 아닌 경우, 고객이 앱에서 직접 처리하도록 안내.
   앱 내 처리 경로: 카라멜 앱 → 좌측 하단 [내 차고] 탭 → (차량이 여러 대인 경우) 상단에서 해당 차량 선택 → 우측 상단의 (구독상품명) 구독중> 버튼 선택 → [구독 관리] → [해지] 버튼
3. 해지 버튼 선택 후 두 가지 옵션 안내:
   - 구독 취소: 구독 즉시 해지. 잔여 세차권은 [세차권 다음에 사용하기] 또는 [세차권 환불 받기] 중 선택
   - 일시 정지: 구독 결제를 일시적으로 중단. 정지 기간은 1개월 / 2개월 / 3개월 / 4개월 중 선택
4. 환불 선택 시: 해당 구독으로 취득한 전체 회차의 미사용 세차권 환불(마지막 결제 회차만이 아님). 회차별로 일부 사용이 있는 경우 사용분은 1회성 상품 정상가 기준 차감. 세부 기준은 「예약 취소 및 환불 규정」 참조.

## 고객 안내 문구
구독 해지 / 일시 정지 방법에 대해 안내드립니다.
카라멜 앱 → 좌측 하단 [내 차고] 탭 → (차량이 여러 대인 경우) 상단에서 해당 차량 선택 → 우측 상단의 (구독상품명) 구독중> 버튼을 선택해 주세요.

구독 관리 페이지에서 [해지] 버튼을 누르시면 아래 두 가지 옵션을 선택하실 수 있습니다.

1. 구독 취소: 구독을 즉시 해지합니다.
   - [세차권 다음에 사용하기]: 세차권을 일부라도 사용하신 상태라면 이 옵션이 더 유리합니다.
   - [세차권 환불 받기]: 구독 기간 전체에서 미사용 세차권을 환불받으실 수 있습니다.

2. 일시 정지: 구독 결제를 일시적으로 멈춥니다. 정지 기간은 1개월 / 2개월 / 3개월 / 4개월 중 선택하실 수 있습니다.

## 주의사항
구독을 통해 지급된 세차권은 별도 유효기간 없이 사용 가능. 환불 선택 시 세차권 일부 사용분은 1회성 상품 정상가 기준으로 차감되므로, 일부 사용 이력이 있는 고객에게는 [세차권 다음에 사용하기] 옵션이 더 유리할 수 있음을 안내.
