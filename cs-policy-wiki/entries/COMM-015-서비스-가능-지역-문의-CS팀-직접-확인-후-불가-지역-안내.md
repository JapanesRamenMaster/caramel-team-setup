## 적용 조건 (when_to_use)
고객이 직접 앱에서 확인이 어려워 CS팀에 문의한 경우, 시/구/동을 수령한 후 서비스 지역 현황 대조 결과 해당 동이 서비스 불가 지역으로 확인된 경우.

## 비적용 조건 (not_when_to_use)
- ⛔ 대조 결과 서비스 가능 지역으로 확인된 경우 (→ '서비스 가능 지역 문의 — CS팀 직접 확인 후 가능 지역 안내' entry 사용)
- ⛔ 고객이 아직 시/구/동을 제공하지 않아 확인 전인 경우 (→ '서비스 가능 지역 문의 — 시/구/동 안내 요청' entry 사용)
- ⛔ 고객이 앱에서 직접 확인 가능한 경우 (→ '서비스 가능 지역 문의 — 고객이 앱에서 직접 확인 가능한 경우' entry 사용)

## 처리 방법
고객이 직접 확인이 어려운 경우 → 시/구/동 수령 후 서비스 지역 현황 대조하여 결과 안내
불가 지역으로 확인된 경우 아래 고객 안내 문구로 안내하며, 해당 위치를 운영팀에 건의사항으로 전달.

## 고객 안내 문구
안녕하세요, 고객님! 카라멜 고객 서비스 팀입니다.
문의하신 위치는 아쉽게도 현재 저희의 서비스 가능 구역에 포함되어 있지 않습니다. 카라멜에 관심을 갖고 문의해 주셨는데, 즉각적인 도움을 드리지 못해 정말 죄송한 마음입니다.
말씀해 주신 위치는 운영팀에 건의사항으로 전달하여 향후 서비스 지역 확장 시 우선적으로 검토될 수 있도록 하겠습니다. 하루빨리 해당 지역에서도 편리하게 서비스를 이용하실 수 있도록 최선을 다해 노력하겠습니다.
소중한 관심 가져주셔서 감사합니다. 추가로 궁금하신 점이 있다면 언제든 편하게 말씀해 주세요.
